## 48.2 자바스크립트와 모듈

초기 자스 일반 `<script>`는 파일을 나누어도 같은 페이지 전역 환경을 공유. 보완하기 위한 CommonJS와 AMD 같은 방식이 등장, ES2015에서 표준 모듈인 ESM 도입

| 방식        | 공개·문법                     | 주로 접하는 환경                   |
| ----------- | ----------------------------- | ---------------------------------- |
| 일반 script | 같은 페이지 전역을 공유       | 브라우저 기존 스크립트             |
| CommonJS    | `module.exports`, `require()` | Node.js 기존 패키지                |
| AMD         | `defined()`, `require()`      | RequireJS 등 기존 로더             |
| ESM         | `export`, `import`            | 브라우저, Node.js, React 빌드 도구 |

현재 Node.js는 CommonJS, ESM을 모두 지원. 브라우저는 ESM을 직접 로드할 수 있음. CommonJS 코드를 브라우저에 사용하려면 번들링 같은 처리가 필요
