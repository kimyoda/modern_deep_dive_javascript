# 27장 배열

배열을 사용할 때 인덱스`length`, 원본 변경 여부, 반환값을 함께 확인

> 배열은 순서가 있는 값을 다루는 객체다. 변환은 `map`, 조건 추출은 `filter`, 누적은 `reduce`로 표현

## 27.1 배열은

배열은 여러 값을 순서대로 관리하는 자료구조다. 배열에 저장된 값은 **요소**다. 요소의 위치를 나타내는 정수는 **인덱스**다. 인덱스는 `0`부터 시작한다

```js
const fruits = ["apple", "banana", "orange"];

console.log(fruits[0]); // apple
console.log(fruits[2]); // orange
console.log(fruits.length); // 3
console.log(typeof fruits); // object
console.log(Array.isArray(fruits)); // true
console.log(Object.getPrototypeOf(fruits) === Array.prototype); // true

for (let index = 0; index < fruits.length; index++) {
  console.log(fruits[index]); // apple -> banana -> orange
}
```

fruits[0]은 첫 요소, fruits[2]는 세 번째 요소다. Length는 배열 길이, 여기서는 빈 슬롯이 없어 실제 요소수와 같음. 배열은 객체이므로 typeof 결과는 object다. 배열 여부는 Array.isArray로 구분

| 인덱스 | 요소   |
| -----: | ------ |
|      0 | apple  |
|      1 | banana |
|      2 | orange |

배열에는 숫자, 문자열, 객체, 함수, 다른 배열 등 모든 JavaScript 값을 담을 수 있음.

```js
const numbers = [10, 20, 30];

for (let i = 0; i < numbers.length; i++) {
  console.log(i, numberes[i]);
}
// 0 10
// 1 20
// 2 30
```

i가 0, 1, 2일때 각각 요소를 읽는다. i가 3이 되면 3 < 3이 false이므로 종료. 마지막 인덱스는 length 자체가 아니라 length - 1이다

| 항목              | 의미                                                 |
| ----------------- | ---------------------------------------------------- |
| 요소              | 배열에 저장한 값                                     |
| 인덱스            | `0`부터 시작하는 요소 위치                           |
| `length`          | 배열의 길이, 인덱스 범위의 끝을 나타내는 값          |
| `Array.prototype` | 배열 인스턴스가 일반적으로 상속하는 메서드 제공 객체 |

숫자, 문자열, 객체, 함수 다른 배열 등 모든 JavaScript 값을 요소로 사용할 수 있다. 같은 목적의 데이터를 일관된 구조로 저장하면 이해하고 처리하기 쉽다

**배열도 객체지만 일반 객체와 동작이 같지는 않다** 배열 인덱스와 `length`가 연결되는 특별한 규칙을 가진다. 일반 객체도 프로퍼티 순회 순서 규칙이 있어 "객체에는 어떤 순서도 없다"고 일반화하지 않음
