# 23장. 실행 컨텍스트

## 체크

- **호출 스택은 코드의 실행, 복귀 순서, 렉시컬 환경은 식별자와 스코프를 관리한다**
- 선언 준비와 실제 값 대입을 구분한다
- var의 초기화, 함수 선언문의 함수 객체 준비, let, const의 TDZ를 비교한다
- 외부 환경 참조는 함수의 정의 환경을 기준으로 정해진다
- 블록 환경 생성과 함수 실행 컨텍스트 생성을 구분한다

| 개념         | 역할                       |
| ---------- | ------------------------ |
| 실행 컨텍스트    | 실행에 필요한 상태와 환경을 명세상으로 표현 |
| 실행 컨텍스트 스택 | 함수 호출과 복귀에 따른 실행 순서 관리   |
| 환경 레코드     | 식별자와 바인딩 상태, 값 관리        |
| 외부 환경 참조   | 상위 스코프의 식별자 검색           |
| this 바인딩   | 해당 실행에 this로 사용할 값       |

책에서 설명하는 렉시컬 환경 모델을 학습한다.

> 전역 객체 프로퍼티, window, sloppy this를 설명하는 부분은 브라우저의 일반 스크립트 기준. ES 모듈과 Node.js CommonJS에서 최상위 스코프와 this가 다르다

## 장 도입

실행 컨텍스트는 자스의 동작 원리를 담고 있는 개념이다. 자스가 스코프를 기반으로 식별자와 식별자에 바인딩된 값(식별자 바인딩)을 관리하는 방식과 호이스팅이 발생하는 이유, 클로저의 동작 방식, 태스크 큐와 함께 동작하는 이벤트 핸들러와 비동기 처리 방식을 이해하는 데 도움이 된다.
