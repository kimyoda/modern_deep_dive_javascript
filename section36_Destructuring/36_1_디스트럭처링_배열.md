# 36장. 디스트럭처링 할당

> 배열 구조 분해는 이터레이터의 순서, 객체 구조 분해는 프로퍼티 키로 값을 꺼낸다. 기본값은 undefined일때만 적용

디스트럭처링은 구조 분해 할당이라고 부름.

| 구분           | 예시                              | 기준                                          |
| -------------- | --------------------------------- | --------------------------------------------- |
| 배열 구조 분해 | `const [a, b] = source`           | 이터레이터가 제공하는 순서                    |
| 객체 구조 분해 | `const { name } = source`         | 프로퍼티 키                                   |
| Rest 요소      | `const [first, ...rest] = source` | 남은 값을 새 배열로 수집                      |
| Rest 프로퍼티  | `const {id, ...rest } = source`   | 남은 자체 열거 가능 프로퍼티를 새 객체로 복사 |

## 36.1 배열 디스트럭처링 할당

### 기본 문법과 할당 순서

```js
const array = [1, 2, 3];

// 기존 인덱스 접근
const oldFirst = array[0];
const oldSecond = array[1];
console.log(oldFirst, oldSecond); // 1 2

const [one, two, three] = array;
console.log(one, two, three); // 1 2 3

const [x, y] = new Set([10, 20]);
console.log(x, y); // 10 20

const [emoji, letter] = "�A";
console.log(emoji, letter); // '�' 'A'
```

일반 배열에 인덱스 순서와 같지만, 정확한 규칙은 **이터레이터가 값을 내놓은 순서**. 배열 이외의 이터러블에 적용

### 선언·할당과 오류

```js
let x;
let y;
[x, y] = [1, 2];
console.log(x, y); // 1 2

[x, y] = [y, x];
console.log(x, y); // 2 1

try {
  const [value] = {};
} catch (error) {
  console.log(error.name); // TypeError
}

// 초기화 없는 구조 분해 선언은 문법 오류
// const [a, b]; // SyntaxError
// let [a, b]; // SyntaxError
```

새 변수를 만들 때 선언과 초기화를 함께 한다. 기존 변수의 재할당·교환이 필요할 때 별도 할당도 유용

length와 인덱스만 있는 일반 유사 배열은 이터러블이 아니면 배열 구조 분해 대상이 아님. 필요하면 Array.from으로 먼저 반환

### 개수 차이·생략·기본값

```js
const [a, b] = [1];
console.log(a, b); // 1 undefined

const [c, d] = [1, 2, 3];
console.log(c, d); // 1 2

const [e, , f] = [1, 2, 3];
console.log(e, f); // 1 3

const [g = 10, h = 20, i = 30] = [1, undefined];
console.log(g, h, i); // 1 20 30

const [j = 10, k = 20, l = 30, m = 40] = [null, 0, false, ""];
console.log(j, k, l, m); // null 0 false ''
```

| 추출값              | 기본값 적용   |
| ------------------- | ------------- |
| 요소 없음·undefined | 적용          |
| null                | 적용하지 않음 |
| 0·false·빈 문자열   | 적용하지 않음 |

기본값 표현식은 필요할 때만 평가. falsy 값을 모두 대체하는 `value || fallback`과 다름

### 정규식 캡처 결과 구조 분해

```js
function parseURL(url = "") {
  const matched = url.match(/^(\w+):\/\/([^/]+)\/(.*)$/);
  if (!matched) {
    return;
  }
  // 0번의 전체 일치 문자열은 건너뜀
  const [, protocol, host, path] = matched;
  return { protocol, host, path };
}

console.log(parseURL("https://developer.mozilla.org/ko/docs/Web/JavaScript"));
// { protocol: 'https', host: 'developer.mozilla.org', path: 'ko/docs/Web/JavaScript' }

console.log(parseURL("not-a-url")); // {}
```

위 정규식은 캡처 결과를 꺼내는 예제. URL 전체 문법 쿼리·프로그래먼트 구분을 완전하게 처리하지 않음

```js
const url = new URL("https://example.com/users?page=2#top");
const { protocol, host, pathname, search, hash } = url;

console.log(protocol); // 'https:'
console.log(host); // 'example.com'
console.log(pathname); // '/users'
console.log(search); // '?page=2'
console.log(hash); // '#top'
```

### Rest 요소

```js
const [first, ...rest] = [1, 2, 3];
console.log(first); // 1
console.log(rest); // [2, 3]
console.log(Array.isArray(rest)); // true

// Rest는 마지막에 오며 뒤에 쉼표를 붙일 수 없음
// const [...all, last] = [1, 2, 3]; // SyntaxError
// const [head, ..tail] = [1, 2, 3]; // SyntaxError
```

Rest 요소는 남은 값을 끝까지 소비. 무한 이터러블에 사용하지 않음
