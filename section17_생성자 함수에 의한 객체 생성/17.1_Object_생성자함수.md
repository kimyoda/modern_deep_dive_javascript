# 17.1 Object 생성자 함수

## 1. Object 생성자 함수란?

`Object` 생성자 함수는 `new` 연산자와 함께 호출하면 **빈 객체**를 생성하여 반환한다.

```js
const person = new Object();
```

위 코드는 빈 객체를 생성하는 코드다.

```js
const person = {};
```

객체 리터럴 방식과 결과적으로 비슷하게 빈 객체를 만들 수 있다.

---

## 2. 빈 객체 생성 후 프로퍼티와 메서드 추가

`new Object()`로 생성한 빈 객체에는 나중에 프로퍼티나 메서드를 추가할 수 있다.

```js
const person = new Object();

person.name = "Lee";

person.sayHello = function () {
  console.log("Hi! My name is " + this.name);
};

console.log(person);
person.sayHello();
```

### 실행 결과

```jsx
{name: "Lee", sayHello: f}
Hi! My name is Lee
```

---

## 3. 핵심 정리

| 구분                    | 설명                                             |
| ----------------------- | ------------------------------------------------ |
| `new Object()`          | 빈 객체를 생성한다                               |
| 프로퍼티 추가           | `person.name = 'Lee'`처럼 추가 가능              |
| 메서드 추가             | `person.sayHello = function () {}`처럼 추가 가능 |
| 일반적인 객체 생성 방식 | 객체 리터럴 `{}`을 더 많이 사용한다              |

---

## 4. 중요한 포인트

반드시 `Object` 생성자 함수를 사용해서 객체를 만들 필요는 없다.

```jsx
const person = new Object();
```

보다는 보통 아래 방식이 더 간단하고 많이 사용된다.

```jsx
const person = {};
```

즉, 객체를 생성할 때는 대부분 **객체 리터럴 방식**을 사용하는 것이 더 간편하다.
