## 19.2 상속과 프로토타입

상속은 어떤 객체의 프로퍼티나 메서드를 다른 객체가 이어받아 사용할 수 있게 하는 방식이다. 상속을 활용하면 불필요한 코드와 데이터의 중복을 제거할 수 있다.

**예제 19-03**

```js
// 생성자 함수
function Circle(radius) {
  this.radius = radius;
  this.getArea = function () {
    // Math.PI는 원주율을 나타내는 상수다.
    return Math.PI * this.radius ** 2;
  };
}

// 반지름이 1인 인스턴스 생성
const circle1 = new Circle(1);
// 반지름이 2인 인스턴스 생성
const circle2 = new Circle(2);

// Circle 생성자 함수는 인스턴스를 생성할 때마다
// 동일한 동작을 하는 getArea 메서드를 새로 생성한다.
// 각 인스턴스가 메서드를 중복 소유하므로 공유하는 편이 바람직하다.
console.log(circle1.getArea === circle2.getArea); // false

console.log(circle1.getArea()); // 3.1415926...
console.log(circle2.getArea()); // 12.566370...
```

`Circle` 생성자 함수가 생성하는 모든 인스턴스는 `radius` 프로퍼티와 `getArea` 메서드를 갖는다. 그러나 인스턴스를 생성할 때마다 동일한 동작을 하는 `getArea` 메서드를 새로 생성하므로 각 인스턴스가 메서드를 중복 소유한다.

상속을 통해 이 중복을 제거할 수 있다. **JavaScript는 프로토타입을 기반으로 상속을 구현한다.**

**예제 19-04**

```js
// 생성자 함수
function Circle(radius) {
  this.radius = radius;
}

// 모든 인스턴스가 getArea 메서드를 공유하도록 프로토타입에 추가한다.
// 프로토타입은 Circle 생성자 함수의 prototype 프로퍼티가 가리킨다.
Circle.prototype.getArea = function () {
  return Math.PI * this.radius ** 2;
};

// 인스턴스 생성
const circle1 = new Circle(1);
const circle2 = new Circle(2);

// 모든 인스턴스는 Circle.prototype에서 동일한 getArea를 상속받는다.
console.log(circle1.getArea === circle2.getArea); // true
console.log(circle1.getArea()); // 3.1415926...
console.log(circle2.getArea()); // 12.566370...
```

`Circle.prototype`은 인스턴스들의 상위 객체 역할을 하며, 인스턴스는 여기에 정의된 프로퍼티와 메서드를 상속받아 사용할 수 있다.

`getArea` 메서드는 한 번만 생성되어 `Circle.prototype`에 할당된다. 각 인스턴스는 자기 상태를 나타내는 `radius` 프로퍼티만 개별적으로 소유하고, 내용이 동일한 메서드는 프로토타입을 통해 공유한다.
