# 16.3 데이터 프로퍼티와 접근자 프로퍼티

- 프로퍼티는 데이터 프로퍼티와 접근자 프로퍼티로 구분할 수 있다.
  - 데이터 프로퍼티(data property)
- 키와 값으로 구성된 일반적은 프로퍼티다. 지금까지 살펴본 모든 프로퍼티는 데이터 프로퍼티다.
  - 접근자 프로퍼티(accessor property)

---

## 16.3.1 데이터 프로퍼티

데이터 프로퍼티는 키와 값으로 구성된 일반적인 프로퍼티다

데이터 프로퍼티는 다음 프로퍼티 어트리뷰트를 갖는다

| 프로퍼티 어트리뷰트 | 디스크립터 프로퍼티 | 설명                                       |
| ------------------- | ------------------- | ------------------------------------------ |
| `[[Value]]`         | `value`             | 프로퍼티 키를 통해 접근했을 때 반환되는 값 |
| `[[Writable]]`      | `writable`          | 프로퍼티 값의 변경 가능 여부               |
| `[[Enumerable]]`    | `enumerable`        | 프로퍼티의 열거 가능 여부                  |
| `[[Configurable]]`  | `configurable`      | 프로퍼티의 재정의 가능 여부                |

객체에 프로퍼티가 생성되면 `[[Value]]`는 프로퍼티 값으로 초기화, `[[Writable]]`, `[[Enumerable]]` `[[Configurable]]`은 기본적으로 `true`가 된다.

프로퍼티 어트리뷰트는 `Object.getOwnPropertyDescriptor` 또는 `Object.getOwnPropertyDescriptors` 메서드로 확인할 수 있다.

접근자 프로퍼티는 값을 직접 저장하지 않고, getter와 setter를 통해 데이터 프로퍼티의 값을 읽거나 변경한다.

### 접근자 프로퍼티 동작 방식

접근자 프로퍼티에 접근하면 내부적으로 다음 과정이 수행된다.

1. 프로퍼티 키가 유효한지 확인한다.
2. 프로토타입 체인에서 프로퍼티를 검색한다.
3. 검색된 프로퍼티가 데이터 프로퍼티인지 접근자 프로퍼티인지 확인한다.
4. 접근자 프로퍼티라면 `[[Get]]`의 값인 getter 함수를 호출하고 그 결과를 반환한다.

### 데이터 프로퍼티와 접근자 프로퍼티 구분

데이터 프로퍼티와 접근자 프로퍼티는 프로퍼티 디스크립터 객체의 구성이 다르다.

- 데이터 프로퍼티: `value`, `writable`, `enumerable`, `configurable`
- 접근자 프로퍼티: `get`, `set`, `enumerable`, `configurable`

예를 들어 일반 객체의 `__proto__`는 접근자 프로퍼티이고, 함수 객체의 `prototype`은 데이터 프로퍼티다.
