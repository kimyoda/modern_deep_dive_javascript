## 45.6 프로미스 정적 메서드

### 45.6.1 Promise.resolve와 Promise.reject

```js
Promise.resolve([1, 2, 3]).then((values) => console.log(values));
Promise.reject(new Error("실패")).catch((error) => console.log(error.message));

const ready = Promise.resolve("이미 준비됨");
console.log(Promise.resolve(ready) === ready); // true
```

`resolve`는 일반 값을 이행된 프로미스로 다루고, 같은 생성자의 프로미스를 받으면 그 객체를 반환. `reject`는 받은 인수를 이유로 거부된 새 프로미스를 만듬

### 45.6.2 Promise.all

모든 작업이 성공해야 다음 단계로 넘어갈 때 사용. 결과 배열은 **완료 순서가 아니라 입력 순서**를 따른다. 하나가 거부되면 반환 프로미스도 거부되나, 이미 시작한 나머지 작업은 자동 취소 되지 않음

```js
function load(value, ms) {
  return new Promise((resolve) => setTimeout(() => resolve(value), ms));
}

async function sequential() {
  const first = await load(1, 300);
  const second = await load(2, 200);
  const third = await load(3, 100);

  return [first, second, third]; // 약 600ms 이상
}

async function concurrent() {
  return Promise.all([load(1, 300), load(2, 200), load(3, 300)]);
  // 약 300ms 이상, 결과는 [1, 2, 3]
}
```

`load(...)`를 호출할 때 작업이 시작. `Promise.all`은 전달받은 작업의 결과를 모은다. 자바스크립트가 여러 스레드에 콜백을 동시에 실행된다는 뜻은 아님. 입력에 일반 값이 섞여도 된다. `Promise.all([1, Promise.resolve(2)])` 결과는 `[1, 2]`

### 45.6.3 Promise.race

**가장 먼저 완료된 작업**의 이행 값이나 거부 이유를 따른다.

```js
Promise.race([
  new Promise((resolve) => setTimeout(() => resolve("응답"), 100)),
  new Promise((_, reject) =>
    setTimeout(() => reject(new Error("시간 초과")), 20),
  ),
]).catch((error) => console.log(error.message)); // 시간 초과
```

시간 초과로 `race`가 거부되어도 원래 작업은 계속될 수 있음. 실제 `fetch` 취속 필요하면 `AbortController`의 신호를 요청에 전달.

### 45.6.4 Promise.allSettled

모든 작업 성공·실패를 각각 확인할 때 사용. 결과 배열 순서는 입력 순서

```js
Promise.allSettled([
  Promise.resolve("프로필"),
  Promise.reject(new Error("알림 조회 실패")),
]).then((results) => console.log(results));

// [
//   { status: 'fulfilled', value: '프로필' },
//   { status: 'rejected', reason: Error('알림 조회 실패') }
// ]
```

### Promise.any 선택 기준

`Promise.any`는 가장 먼저 **성공한** 값을 선택. 전부 실패하면 `AggregateError`로 거부. 입력이 비면 `all`과 `allSettled`는 빈 배열로 이행, `any`는 거부, `race`는 대기 상태로 남음

| 동작                                | 선택                 |
| ----------------------------------- | -------------------- |
| 모든 값이 필요                      | `Promise.all`        |
| 성공과 실패를 전부 보고 싶음        | `Promise.allSettled` |
| 성공·실패와 관계없이 첫 완료가 필요 | `Promise.race`       |
| 실패한 작업은 건너뛰고 성공이 필요  | `Promise.any`        |
