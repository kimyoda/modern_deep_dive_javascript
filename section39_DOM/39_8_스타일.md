## 39.8 스타일

### 39.8.1 인라인 스타일 조작

elemt.style 해당 요소의 **인라인 스타일 선언**을 다루는 객체. 외부 스타일시트까지 합친 최종 스타일을 제공하는 것은 아님

#### 인라인 스타일로 파란 글자·노란 상자 만들기

공통 HTML의 `#box`에 다음 JavaScript를 실행. 일반 스타일 규칙은 앞의 style.css에 두고, 여기서는 style API의 효과를 확인

```js
const box = document.getElementById("box");

box.style.color = "blue";
box.style.width = "100px";
box.style.height = "100px";
box.style.backgroudColor = "yellow";

console.log(box.style.width); // '100px'
console.log(box.getAttribute("style")); // color, width, height, background-color 선언을 확인
```

| 확인                   | 내용                                |
| ---------------------- | ----------------------------------- |
| Elements               | div의 style 어트리뷰트가 생성       |
| Styles의 element.style | JavaScript로 넣은 인라인 선언       |
| Styles의 .box 규칙     | 별도 CSS 파일 padding·border        |
| Computed               | 캐스케이드 등을 반영한 실제 적용 값 |
| 화면                   | 파란 글자와 노란 배경               |

CSS width 100px은 content-box 기준으로 콘텐츠 영역의 너비. padding·border가 있으면 상자 전체 너비는 더 커진다

```js
const box = document.getElementById("box");

box.style.setProperty("background-color", "yellow");
console.log(box.style.getPropertyValue("background-color")); // 'yellow'

box.style.removeProperty("background-color");
console.log(box.style.backgroundColor); // ''
```

camelCase 프로퍼티나 setProperty의 하이폰 이름을 사용할 수 있음. width에 보통 단위가 필요하나 opacity처럼 단위가 없는 속성도 있음
cssText 대입은 인라인 선언 전체를 바꿀 수 있어 기존 선언 유지 여부를 확인

### 39.8.2 클래스 조작

클래스는 CSS 규칙을 적용할 이름을 JavaScript에서 바꾸는 방식. 표현 규칙은 CSS 파일에 모으고 JavaScript는 상태에 따라 클래스를 조작하면 관리하기 쉬움

#### className

```js
const box = document.getElementById("box");

console.log(box.className); // 'box'
box.className = "box active";
console.log(box.className);
```

className은 전체 클래스 문자열. 일부 토큰만 바꾸려다 다른 클래스까지 덮어쓰지 않도록 주의

#### classList

classList는 클래스 토큰을 다루는 live DOMTokenList다

| 메서드                  | 동작                       | 반환값            |
| ----------------------- | -------------------------- | ----------------- |
| add(...tokens)          | 토큰 추가                  | undefined         |
| remove(...tokens)       | 토큰 제거                  | undefined         |
| item(index)             | 해당 위치의 토큰           | 문자열 또는 null  |
| contains(token)         | 존재                       | boolean           |
| replace(old, next)      | 토큰 교체                  | 교체 여부 boolean |
| toggle(token)           | 존재하면 제거, 없으면 추가 | 처리 후 존재 여부 |
| toggle(token, force)    | true면 추가, false면 제거  | 처리 후 존재 여부 |
| forEach(callback)       | 각 토큰 순회               | undefined         |
| entries / keys / values | 순회용 이터레이터          | iterator          |

```js
const box = document.getElementById("box");

box.classList.add("active", "selected");
console.log(box.classList.contains("active")); // true

box.classList.replace("selected", "highlight");
box.classList.remove("active");
box.classList.toggle("active");

console.log([...box.classList]); // ['box', 'highlight', 'active']
console.log(box.classList.item(99)); // null
```

하나의 토큰에 공백을 넣을 수 없음. `add('a b')` 대신 `add('a', 'b')`를 사용. DOMTokenList의 supports는 지원 토큰 집합이 정의된 경우를 위한 API, 임의의 CSS 클래스가 유효한지 검사하는 메서드가 아님

### 39.8.3 요소에 적용될 스타일 참조

getComputedStyle는 외부 CSS·인라인 선언·상속·기본 스타일 등을 반영 **resovled style 값**을 읽기 위한 API.결과를 수정해 요소 스타일을 바꾸는 요도로 사용하지 않음

```js
const box = document.getElementById("box");

// 공통 HTML 초기 상태: padding은 외부 CSS에 있음
console.log(box.style.padding); // ''
console.log(getComputedStyle(box).paddingTop); // '8px'

box.style.color = "blue";
console.log(getComputedStyle(box).color); // 'rgb(0, 0, 255)';

const before = getComputedStyle(box, "::before");
console.log(before.content); // '"DOM "': 따옴표가 포함된 CSS 문자열
```

| 목적                    | API                                   |
| ----------------------- | ------------------------------------- |
| 인라인 선언 읽기·변경   | element.style                         |
| 적용된 스타일 값 읽기   | getComputedStyle(element)             |
| 의사 요소의 스타일 읽기 | getComputedStyle(element, '::before') |
| 요소의 위치·크기 확인   | getBoundingChilentRect 등             |

스타일 변경과 레이아웃 값 읽기를 반복 교차하면 동기 계산 비용이 커질 수 있음. 필요한 읽기와 쓰기를 묶어 처리
