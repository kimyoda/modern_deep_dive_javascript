## 27.6 배열 요소의 추가와 갱신

```js
const numbers = [0];

const numbers = [0];

// 인덱스 1에 새로운 요소 추가
numbers[1] = 1;

// 인덱스 1의 기존 요소 갱신
numbers[1] = 10;

// 인덱스 4에 새로운 요소 추가
// 인덱스 2, 3은 빈 슬롯으로 남음
numbers[4] = 40;

// 배열의 길이
console.log(numbers.length); // 5

// 인덱스 1의 값
console.log(numbers[1]); // 10

// 실제 존재하는 인덱스 확인
console.log(Object.keys(numbers)); // ['0', '1', '4']

// 배열 전체 확인
console.log(numbers); // [0, 10, <2 empty items>, 40]

// 빈 슬롯 접근
console.log(numbers[2]); // undefined

// 요소 존재 여부 확인
console.log(2 in numbers); // false
```

큰 인덱스에 바로 추가하면 중간에 빈 슬롯이 생김

### 배열 요소와 일반 프로퍼티

```js
const array = [];

array[0] = 1;
array["1"] = 2;
array[-1] = 3;
array[1.5] = 4;
array.foo = 5;
array["01"] = 6;

console.log(array.length); // 2
console.log(array[-1]); // 3
console.log(array.foo); // 5
console.log(array["01"]); // 6
```

| 키              | 배열 인덱스 여부 | `length` 영향 |
| --------------- | ---------------- | ------------- |
| `0`, `'0'`      | 예               | 필요하면 증가 |
| `1`, `'1'`      | 예               | 필요하면 증가 |
| `-1`, `1.5`     | 아니요           | 없음          |
| `'foo'`, `'01'` | 아니요           | 없음          |
| `'4294967295'`  | 아니요           | 없음          |

`'01'`은 `'1'`과ㅣ 같은 키가 아니다. 일반 프로퍼티를 배열에 붙여도 보통의 배열 요소 순회 대상에 포함되지 않음
