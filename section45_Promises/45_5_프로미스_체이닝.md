## 45.5 프로미스 체이닝

게시글을 읽어야 작성자 ID를 알 수 있어, 두 요청은 순서대로 실행. 아래는 JSONPlaceholder 예제 경로 사용

```js
const base = "https://jsonplaceholder.typicode.com";

requestJson(base + "/posts/1")
  .then(({ userId }) => requestJson(base + "/users/" + userId))
  .then((user) => console.log(user.name))
  .catch((error) => console.error(error.message));
```

화살표 함수 본문을 중괄호로 작성하면 `return`을 명시. 빠뜨리면 다음 `then`이 `undefined`를 받고 두 번째 요청의 완료를 기다리지 않음

```js
async function getPostAuthor(baseUrl, postId) {
  const { userId } = await requestJson(baseUrl + "/posts/" + postId);
  return requestJson(baseUrl + "/users" + userId);
}

getPostAuthor("https://jsonplaceholder.typicode.com", 1)
  .then((user) => console.log(user.name))
  .catch((error) => console.log(error.message));
```

`await`는 해당 `async` 함수 다음 줄을 기다리게 한다. `async` 함수도 프로미스를 반환
