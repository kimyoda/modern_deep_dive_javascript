## 31.2 정규 표현식 생성

| 방식   | 예시                  | 상황               |
| ------ | --------------------- | ------------------ |
| 리터럴 | /is/i                 | 패턴을 코드에 고정 |
| 생성자 | new RegExp('is', 'i') | 실행 중 패턴 구성  |

```js
const text = "Is this all there is?";
const literal = /is/i;
const constructor = new RegExp("is", "i");

console.log(literal.test(text)); // true
console.log(constructor.test(text)); // true
```

문자열로 패턴을 만들 때 문자열과 정규식의 이스케이프를 구분

```js
const literal = /\d+/g;
const constructor = new RegExp("\\d+", "g");

console.log("A12 B34".match(literal)); // ['12', '34']
console.log("A12 B34".match(constructor)); // ['12', '34']
```

패턴의 공백은 사용할 수 있고 보통 공백 문자 자체를 뜻함. JavaScript에 일반적인 확장 모드 x 플래그가 없어 패턴 안에 설명용 공백이나 주석을 자유롭게 넣을 수 있다는 건 아님
