## 45.4 프로미스 에러 처리

같은 `then`에 넣은 두 번째 콜백은 **앞 프로미스 거부**를 처리. 첫 번째 콜백 안에서 새로 던진 예외는 `then`이 반환한 다음 프로미스를 거부하므로 뒤에 붙인 `catch`에서 잡는다

```js
Promise.resolve("응답")
  .then(
    () => {
      throw new Error("후속 처리 실패");
    },
    (error) => console.error("이 예제에서 실행되지 않음:", error.message),
  )
  .catch((error) => console.error(error.message)); // 후속 처리 실패
```

`catch`에 값을 반환하면 그 값으로 복구된다. 오류를 호출자에게 계속 전달하려면 `throw error`를 사용. `catch(console.error)`는 오류를 출력하고 정상 종료, 이어지는 체인은 보통 `undefined`로 이행
