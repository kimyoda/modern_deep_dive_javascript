## 20.1 strict mode란

**예제 20-01**

```js
function foo() {
  x = 10;
}
foo();

console.log(x); // 10
```

`foo` 함수 내부에서 선언하지 않은 `x`에 값을 할당한다. JavaScript 엔진은 `x`가 어디에 선언되어 있는지 스코프 체인을 따라 검색한다.

먼저 `foo` 함수의 스코프에서 `x`를 찾고, 선언이 없으면 상위 스코프에서도 검색한다. 끝까지 찾지 못한 상태에서 비엄격 모드로 대입하면, 일반적인 스크립트에서는 전역 객체에 `x` 프로퍼티가 동적으로 생성된다.

전역 객체의 `x` 프로퍼티는 마치 전역 변수처럼 사용할 수 있다. 이러한 현상을 **암묵적 전역(implicit global)**이라고 한다.

ES5부터 **strict mode(엄격 모드)**가 도입되었다. 이 모드에서는 암묵적 전역처럼 실수를 유발하기 쉬운 동작을 제한하고, 일부 잘못된 코드에 명시적인 오류를 발생시킨다.

> **실습 참고:** 예제 20-01은 strict mode가 아닌 독립된 일반 스크립트 또는 CommonJS 환경을 가정한다. ES 모듈에서는 기본적으로 strict mode이므로 선언하지 않은 `x`에 대입하면 `ReferenceError`가 발생한다.
