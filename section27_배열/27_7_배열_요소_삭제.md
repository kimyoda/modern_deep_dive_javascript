## 27.7 배열 요소의 삭제

### `delete`와 `splice`의 차이

```js
const a = [1, 2, 3];
delete a[1];

console.log(a.length); // 3
console.log(Object.hasOwn(a, 1)); // false

const b = [1, 2, 3];
const removed = b.splice(1, 1);

console.log(b); // [1, 3];
console.log(removed); // [2]
console.log(b.length); // 2
```

| 방식                     | 결과                            | 길이      |
| ------------------------ | ------------------------------- | --------- |
| `delete array[index]`    | 프로퍼티 삭제, 빈 슬롯 생성     | 유지      |
| `array.splice(index, 1)` | 요소 제거, 뒤쪽 요소 당김       | 감소      |
| `array.filter(...)`      | 조건에 맞는 요소로 새 배열 생성 | 원본 유지 |

일반적인 목록에 요소를 제거하려면 `splice`나 `filter` 등 목적에 맞는 메서드를 사용
