## 19.5 프로토타입 생성 시점

### 19.5.1 사용자 정의 생성자 함수와 프로토타입 생성 시점

생성자 함수로 호출할 수 있는 함수(`constructor`)는 함수 정의가 평가되어 함수 객체가 생성되는 시점에 프로토타입도 함께 생성된다.

**예제 19-20**

```js
// 함수 선언문은 선언을 준비하는 과정에서 함수 객체가 생성되므로
// 선언문보다 앞에서도 Person.prototype을 조회할 수 있다.
console.log(Person.prototype); // { constructor: [Function: Person] } (표시 형식은 환경에 따라 다름)

// 생성자 함수
function Person(name) {
  this.name = name;
}

// Person은 constructor이므로 prototype이 존재한다.
console.log(Person.prototype !== undefined); // true

// 화살표 함수는 non-constructor이므로 prototype을 생성하지 않는다.
const NonConstructor = (name) => name;
console.log(NonConstructor.prototype); // undefined
```

함수 선언문은 해당 스코프에서 선언을 준비하는 과정에 함수 객체가 만들어진다. 생성된 프로토타입은 `Person` 생성자 함수의 `prototype` 프로퍼티에 바인딩된다.

기본적으로 생성자 함수의 프로토타입 객체는 `constructor` 고유 프로퍼티를 갖고, `Object.prototype`을 상속한다.

일반 함수 선언문과 함수 표현식의 기본 `prototype` 객체도 함수 객체 생성 시 준비된다. 단, 클래스 상속이나 명시적인 프로토타입 교체가 있으면 그 관계는 달라질 수 있다.

### 19.5.2 빌트인 생성자 함수와 프로토타입 생성 시점

`Object`, `String`, `Number`, `Function`, `Array`, `RegExp`, `Date`, `Promise` 등의 빌트인 생성자 함수 역시 관련 프로토타입과 함께 준비된다. 일반적으로 JavaScript 실행 환경이 초기화되는 과정에서 생성된다.

**참고: 전역 객체**

전역 객체는 코드가 실행되기 전에 JavaScript 엔진이 생성하는 특수한 객체다. 브라우저에서는 `window`(전역 객체를 가리키는 대표적인 이름), Node.js에서는 `global`을 통해 접근할 수 있다. 두 환경 모두 표준적인 접근 방법으로 `globalThis`를 사용할 수 있다.

전역 객체에는 표준 빌트인 객체와 환경에 따른 호스트 API가 제공된다. 전통적인 스크립트의 최상위 `var` 선언과 함수 선언도 전역 객체의 프로퍼티가 될 수 있지만, Node.js의 CommonJS 모듈이나 ES 모듈에서의 최상위 선언은 다르게 동작한다.

표준 빌트인에는 생성자 함수, 일반 함수, 객체 및 원시 값 관련 기능이 포함된다. 예를 들어 `Symbol`, `BigInt`는 `new`로 호출할 수 없고, `Math`, `JSON`, `Reflect`는 생성자 함수가 아닌 일반 객체다.

**예제 19-22**

```js
// window는 브라우저 전용이므로 이 코드는 브라우저 환경에서 실행한다.
// Object 생성자 함수는 전역 객체 window의 프로퍼티다.
console.log(window.Object === Object); // true
```

`Object`는 전역 객체의 프로퍼티이며 실행 환경을 초기화할 때 준비된다. 생성자 함수 또는 리터럴 표기법으로 객체가 생성되면, 생성 방식에 따라 결정된 프로토타입이 해당 객체의 `[[Prototype]]` 내부 슬롯에 연결된다.
