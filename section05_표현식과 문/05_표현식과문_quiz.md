## section05 표현식과 문

### 1. 다음 중 숫자 리터럴은 무엇인지

- A. `42`
- B. `'42'`
- C. `40 + 2`
- D. `score`

<detail>
<summary>정답과 해설 보기</summary>

**정답 A**

- **A**: `42`는 숫자 값을 코드에 직접 적은 숫자 리터럴.
- **B**: 따옴표로 감싼 `'42'`는 문자열 리터럴.
- **C**: `40 + 2`는 두 숫자 리터럴과 덧셈 연산자로 이루어진 표현식. 평가 결과는 숫자 `42`
- **D**: `score`는 식별자. 변수가 선언되고 초기화되어 있으면 그 변수의 값을 읽는 표현식으로 쓸 수 있음

</detail>

### 2. 다음 코드를 토큰 단위로 올바르게 나눈 것은 무엇인지

```js
var count = 3;
```

- A. `var count` / `=` / `3` / `;`
- B. `var` / `count` / `= 3` / `;`
- C. `var` / `count` / `=` / `3;`
- D. `var` / `count` / `=` / `3` / `;`

<detail>
<summary>정답과 해설 보기</summary>

**정답 D**

- **A**: `var`는 키워드, `count`는 식별자이므로 각각 하나의 토큰이다.
- **B**: `=`는 연산자, `3`은 숫자 리터럴므로 두 토큰으로 나뉜다.
- **C**: `3`에 `;`이 붙어 있어도 숫자 리터럴과 세미콜론은 별개의 토큰.
- **D**: 문법적으로 의미가 있는 기본 단위 다섯 개를 각각 분리.

</detail>

### 3. var result = \_\_\_;`의 빈칸에 넣을 수 있는 코드는?

- A. `var count = 1`
- B. `2 * 3`
- C. `if (true) {}`
- D. `while (false) {}`

<detail>
<summary>정답과 해설 보기</summary>

**정답 B**

- **A**: `var count = 1`은 변수 선언문. 빈칸에 초기값을 구할 표현식이 필요.
- **B**: `2 * 3`은 `6`으로 평가되는 표현식으로 `result`의 초기값을 지정하는 자리에 쓸 수 있음.
- **C**: `if (true) {}`은 조건에 따라 블록을 실행하는 조건문. 초기값 자리에 넣으면 문법 오류가 발생.
- **D**: `while (false) {}`는 반복 실행을 제어하는 반복문. 초기값 자리에 쓰려면 값으로 평가되는 표현식이 필요.

</detail>

### 4. 다음 코드는 어떤 두 값을 출력하는지

```js
var points = 0;
var result = (points = 7);
console.log(points, result);
```

- A. `0 7`
- B. `7 undefined`
- C. `7 7`
- D. `0 0`

<detail>
<summary>정답과 해설 보기</summary>

**정답 C**

- **A**: 괄호 안의 `points = 7`이 실행되면 `points`값도 `7`로 바뀐다.
- **B**: 할당 표현식 `points = 7`로 평가. 그 평가 결과가 `result`에 저장
- **C**: `points = 7`은 `points`에 `7`을 저장하는 동시에 `7`로 평가. 두 변수에 모두 `7`을 읽는다
- **D**: `0`은 `points`의 초기값. 둘째 줄이 실행되며 `points`와 `result`에 각각 `7`이 저장.

</detail>

### 5. 다음 코드 출력 결과는 무엇인지

```js
function getScore() {
  return;
  100;
}

console.log(getScore());
```

- A. `100`
- B. `null`
- C. `SyntaxError` 발생
- D. `undefined`

<detail>
<summary>정답과 해설 보기</summary>

**정답 D**

- **A**: 줄바꿈 으로 `100;`은 별도의 표현식 문으로 해석. 함수는 그 앞의 `return;`에 종료
- **B**: 함수 `null`을 반환하려면 `return null;`처럼 반환할 값을 지정해야 한다.
- **C**: 세미콜론 자동 삽입 후 `return;`과 `100;`은 각각 문법적으로 유효한 문이다.
- **D**: `return`바로 뒤의 줄바꿈 때문에 세미콜론 자동 삽입(ASI)이 적용. `return;`이 실행되면 반환값은 `undefined`이다

</detail>

### 6. 실행이 끝났을 때 `total`에 저장된 값은 무엇인지?

```js
var subtotal = 8;
var total = subtotal + 4;
```

- A. `"subtotal + 4"`
- B. `8`
- C. `12`
- D. `undefined`

<detail>
<summary>정답과 해설 보기</summary>

**정답 C**

- **A**: `"subtotal + 4"`처럼 따옴표로 감싸서 작성하면 해당 문자가 문자열 값으로 저장. 덧셈 표현식을 평가
- **B**: `8`은 `subtotal`을 참조할 때 읽는 값. `total`에 값에 `4`을 더한 결과가 저장
- **C**: `subtotal + 4`는 `8 + 4`로 계산, 평가 결과인 `12`가 `total`에 할당
- **D**: `undefined`는 `var total`을 처리할 때 초기값. 둘째 줄까지 실행하면 덧셈 결과가 할당

</detail>

### 7. 다음 코드에 표현식과 문을 올바르게 설명한 것은?

`score`에 숫자 값이 이미 저장되어 있다고 가정

```js
if (score > 0) {
  console.log(score);
}
```

- A. `if`문 전체를 변수의 초기값 자리에 쓸 수 있음
- B. `score > 0`은 불리언 값으로 평가되는 조건 표현식
- C. `if` 다음 괄호 안에는 변수 선언문이 들어간다
- D. 블록은 조건의 평가 결과와 관계없이 실행

<detail>
<summary>정답과 해설 보기</summary>

**정답 B**

- **A**: 변수의 초기값 자리에 값으로 평가할 표현식이 표현. 예제의 `if`는 조건에 따라 블록 실행을 제어하는 문.
- **B**: `score > 0`은 비교 표현식. `score`가 `0`보다 크면 `true`, 그 외에 `false`로 평가
- **C**: `if` 다음 괄호 안은 조건을 평가할 표현식 자리. 여기서 `score > 0`이 역할
- **D**: 코드 블록은 조건이 `true`로 평가될 때 실행

</detail>

### 8. `double(4)`를 `+` 연산자의 왼쪽에 쓸 수 있는 이유는?

```js
function double(n) {
  return n * 2;
}

var result = double(4) + 1;
```

- A. 모든 문을 `+`의 피연산자로 쓸 수 있기 때문
- B. 함수를 호출하면 함수 이름이 문자열로 바뀐다
- C. 함수 호출이 반환값으로 평가되는 표현식
- D. 함수 선언문 자체가 숫자로 평가

<detail>
<summary>정답과 해설 보기</summary>

**정답 C**

- **A**: `+`의 피연산자 자리에 값으로 평가할 표현식이 필요. 변수 선언문을 그 자리에 쓰면 문법 오류가 발생
- **B**: `double`은 호출할 함수를 찾는 데 쓰는 식별자. 호출에 얻는 값은 함수가 반환한 숫자 `8`이다
- **C**: `double(4)`는 반환된 값 `8`로 평가되는 호출 표현식. `8 + 1`을 계산한 결과 `9`가 `result`에 저장
- **D**: `function double(n) { ... }`은 함수를 선언하는 문. `8`은 `double(4)`를 호출했을 때 얻는 반환값

</detail>

### 9. 다음 코드의 출력 결과는 무엇인지

```js
var values = [10, 20][0];
console.log(values);
```

- A. `[10 20]`
- B. `undefined`
- C. `SyntaxError` 발생
- D. `10`

<detail>
<summary>정답과 해설 보기</summary>

**정답 D**

- **A**: 첫 줄 끝에 세미콜론을 넣었으면 배열 `[10, 20]`이 `values`에 저장. 코드에서 둘째 줄의 `[0]`이 첫 줄과 이어진다
- **B**: 배열의 인덱스 `0`에 실제로 첫 번째 요소인 `10`이 들어있음
- **C**: 배열 리터럴에 `[0]`을 바로 붙이면 첫 요소에 접근하는 유효한 표현식
- **D**: 첫 줄과 둘째 줄은 `var values = [10, 20][0];`처럼 해석. 줄이 바뀌어도 앞의 표현식을 이어 쓸 수 있어 첫 줄 끝에는 세미콜론이 자동 삽입되지 않음.

</detail>

### 10. 콘솔에 표시되는 결과와 변수에 저장된 값은 각각 무엇인지?

개발자 도구 콘솔에 다음을 입력 가정

```js
var quizTotal = 3 + 4;
```

- A. 콘솔 표시 `undefined` / 저장된 값 `7`
- B. 콘솔 표시 `7` / 저장된 값 `7`
- C. 콘솔 표시 `undefined` / 저장된 값 `undefined`
- D. 콘솔 표시 `7` / 저장된 값 `undefined`

<detail>
<summary>정답과 해설 보기</summary>

**정답 A**

- **A**: 선언문을 단독으로 평가, 콘솔에서 결과가 `undefined`로 표시, 명세상 선언문 자체의 완료 값은 비어 있고, `3 + 4`를 `7`은 `quizTotal`에 저장
- **B**: `3 + 4`만 콘솔에 입력하면 `7`이 표시. 문제에서 표현식을 포함한 변수 선언문 전체를 실행
- **C**: 콘솔에 `undefined`가 표시되어 선언문 안의 할당은 실행. 다음 줄에서 `quizTotal`을 입력하면 `7`을 확인
- **D**: `7`은 우변 표현식의 평가 결과. 선언문이 실행될 때 값이 `quizTotal`에 저장

</detail>
