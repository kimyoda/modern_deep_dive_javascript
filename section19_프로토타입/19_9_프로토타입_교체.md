# 19.9 프로토타입의 교체

프로토타입은 다른 객체로 변경할 수 있다. 생성자 함수의 `prototype` 프로퍼티를 교체하거나 인스턴스의 프로토타입을 직접 교체하는 방법이 있다.

## 19.9.1 생성자 함수에 의한 프로토타입 교체

**예제 19-40**

```js
const Person = (function () {
  function Person(name) {
    this.name = name;
  }

  // 1. 생성자 함수의 prototype 프로퍼티를 통해 프로토타입을 교체
  Person.prototype = {
    sayHello() {
      console.log(`Hi! My name is ${this.name}`);
    },
  };

  return Person;
})();

const me = new Person("Kim");
```

예제에서 `Person.prototype`에 객체 리터럴을 할당했다. 이후 `Person` 생성자 함수로 생성할 인스턴스의 기본 프로토타입을 교체한 것이다.

새 프로토타입 객체에 고유 `constructor` 프로퍼티가 없으므로 `me.constructor`를 검색하면 `Person`이 아닌 `Object.prototype.constructor`, 즉 `Object`가 나온다.

**예제 19-41**

```js
// 프로토타입을 교체하면 constructor 프로퍼티와 생성자 함수 간의 연결이 파괴된다
console.log(me.constructor === Person); // false
// 프로토타입 체인을 따라 Object.prototype의 constructor 프로퍼티가 검색된다
console.log(me.constructor === Object); // true
```

기존 기본 프로토타입에 있던 `constructor` 연결이 더 이상 새 프로토타입에 존재하지 않는다.

**예제 19-42**

```js
const Person = (function () {
  function Person(name) {
    this.name = name;
  }

  // 생성자 함수의 prototype 프로퍼티를 통해 프로토타입을 교체
  Person.prototype = {
    // constructor 프로퍼티와 생성자 함수 간의 연결을 설정
    constructor: Person,
    sayHello() {
      console.log(`Hi! My name is ${this.name}`);
    },
  };
  return Person;
})();

const me = new Person("Kim");

// constructor 프로퍼티가 생성자 함수를 가리킨다
console.log(me.constructor === Person); // true
console.log(me.constructor === Object); // false
```

## 19.9.2 인스턴스에 의한 프로토타입 교체

인스턴스의 프로토타입은 `Object.getPrototypeOf`로 조회하고 `Object.setPrototypeOf`로 변경할 수 있다. `__proto__` 접근자를 사용하는 방법도 있으나, 직접 사용은 권장되지 않는다. 이 방식은 **이미 생성된 객체의 프로토타입**을 변경한다.

**예제 19-43**

```js
function Person(name) {
  this.name = name;
}

const me = new Person("Lee");

// 프로토타입으로 교체할 객체
const parent = {
  sayHello() {
    console.log(`Hi! My name is ${this.name}`);
  },
};

// 1 me 객체의 프로토타입을 parent 객체로 교체한다
Object.setPrototypeOf(me, parent);
// me.__proto__ = parent;

me.sayHello(); // Hi! My name is Lee
```

`me` 객체의 프로토타입을 `parent` 객체로 교체했다.

`parent`에 고유 `constructor`가 없으므로 `me.constructor`는 상위 프로토타입에서 발견되는 `Object`를 가리킨다. 이것이 실제 생성 이력을 변경하는 것은 아니다.

**예제 19-44**

```js
// 프로토타입을 교체하면 constructor 프로퍼티와 생성자 함수간의 연결이 파괴
console.log(me.constructor === Person); // false
// 프로토타입 체인을 따라 Object.prototype의 constructor 프로퍼티가 검색
console.log(me.constructor === Object); // true
```

생성자 함수의 `prototype` 연결과 이미 생성된 인스턴스의 프로토타입 연결을 함께 복구하는 예제다.

**예제 19-45**

```js
function Person(name) {
  this.name = name;
}

const me = new Person("Kim");

// 프로토타입으로 교체할 객체
const parent = {
  // constructor 프로퍼티와 생성자 함수 간의 연결을 설정
  constructor: Person,
  sayHello() {
    console.log(`Hi! My name is ${this.name}`);
  },
};

// 생성자 함수의 prototype 프로퍼티와 프로토타입 간의 연결을 설정
Person.prototype = parent;

// me 객체의 프로토타입을 parent 객체로 교체한다
Object.setPrototypeOf(me, parent);
// me.__proto__ = parent;

me.sayHello(); // Hi! My name is Kim

// constructor 프로퍼티가 생성자 함수를 가리킨다
console.log(me.constructor === Person); // true
console.log(me.constructor === Object); // false

// 생성자 함수의 prototype 프로퍼티가 교체된 프로토타입을 가리킨다
console.log(Person.prototype === Object.getPrototypeOf(me)); // true
```

### 생성자 prototype 교체와 기존 인스턴스의 차이

`Person.prototype`에 새 객체를 대입해도 기존 인스턴스의 프로토타입이 자동으로 변경되지는 않는다.

```js
function Person(name) {
  this.name = name;
}

const oldPrototype = Person.prototype;
const before = new Person("before");

Person.prototype = {
  constructor: Person,
  sayHello() {
    return this.name;
  },
};

const after = new Person("after");
console.log(Object.getPrototypeOf(before) === oldPrototype); // true
console.log(Object.getPrototypeOf(after) === Person.prototype); // true
console.log(before instanceof Person); // false
console.log(after instanceof Person); // true
```

| 동작                                | 객체                                                   |
| ----------------------------------- | ------------------------------------------------------ |
| `Person.prototype = 새객체`         | 이후 `new Person()`으로 만들 인스턴스                  |
| `Object.setPrototypeOf(me, 새객체)` | 이미 존재하는 `me` 인스턴스의 프로토타입               |
| `Person.prototype.sayHello = 함수`  | prototype을 상속하는 기존, 신규 인스턴스의 메서드 탐색 |

실행 중 프로토타입 교체는 성능에 영향을 줄 수 있다. 가능하면 객체를 생성할 때 `Object.create`, 생성자 함수 또는 클래스로 프로토타입 연결을 정하는 편이 일반적이다.
