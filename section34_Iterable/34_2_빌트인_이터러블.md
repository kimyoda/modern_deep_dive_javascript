## 34.2 빌트인 이터러블

| 자료구조                         | 기본 순회 값                    |
| -------------------------------- | ------------------------------- |
| Array                            | 요소값                          |
| String                           | Unicode 코드 포인트 단위 문자열 |
| Map                              | `[key, value]` 배열             |
| Set                              | 요소값                          |
| TypedArray                       | 숫자 요소값                     |
| arguments                        | 전달된 인수값                   |
| 브라우저 NodeList·HTMLCollection | DOM 요소 등 컬렉션 항목         |

DOM 컬렉션은 브라우저 API이고 실제 환경의 Symbol.iterator 지원을 확인. 문자열 순회는 UTF-16 코드 단위보다 큰 코드 포인트를 처리, 복합 이모지 등 화면 글자 단위와 항상 같지 않음

```js
console.log([..."�A"]); // ['�', 'A']
console.log([...new Set([1, 1, 2])]); // [1, 2]
console.log([...new Map(["name", "Lee"])]); // [['name', 'Lee']]
console.log([...new Uint8Array([10, 20])]); // [10, 20]
```
