## 27.5 배열 요소의 참조

```js
const numbers = [10, 20];
const index = 1;

console.log(numbers[index]); // 20
console.log(numbers["1"]); // 20
console.log(numbers[2]); // undefined
```

대괄호 안에 표현식을 사용할 수 있다. `numbers[1]`과 `numbers['1']`은 같은 인덱스 프로퍼티에 접근

없는 요소를 읽었을 때 `undefined`와 값으로 저장한 `undefined`를 구분하려면 프로퍼티 존재 여부도 확인한다
