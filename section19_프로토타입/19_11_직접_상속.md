# 19.11 직접 상속

## 19.11.1 Object.create에 의한 직접 상속

`Object.create` 메서드는 프로토타입을 명시적으로 지정해 새로운 객체를 생성한다. 객체 생성에는 내부 추상 연산이 사용된다. 첫 번째 인수로 새 객체가 상속할 프로토타입 객체 또는 `null`을 전달한다.

```text
/**
*
* 지정된 프로토타입 및 프로퍼티를 갖는 새로운 객체를 생성하여 반환
*@param{Object} prototype - 생성할 객체의 프로토타입으로 지정할 객체
*@param{Object} [propertiesObject] - 생성할 객체의 프로퍼티를 갖는 객체
*@return{Object} 지정된 프로토타입 및 프로퍼티를 갖는 새로운 객체
*/
Object.create(prototype[, propertiesObject])
```

**예제 19-51**

```js
// 프로토타입이 null인 객체를 생성한다. 생성된 객체는 프로토타입 체인의 종점에 위치한다
// obj -> null
let obj = Object.create(null);
console.log(Object.getPrototypeOf(obj) === null); // true
// Object.prototype을 상속받지 못함
try {
  console.log(obj.toString());
} catch (error) {
  console.log(error.name); // TypeError
}

// obj => Object.prototype -> null
// obj => {}; 와 동일
obj = Object.create(Object.prototype);
console.log(Object.getPrototypeOf(obj) === Object.prototype); // true

// obj -> Object.prototype -> null
// obj = {x: 1}; 와 동일
obj = Object.create(Object.prototype, {
  x: { value: 1, writable: true, enumerable: true, configurable: true },
});

const myProto = { x: 10 };
// 임의의 객체를 직접 상속받는다
// obj -> myProto -> Object.prototype -> null
obj = Object.create(myProto);
console.log(obj.x); // 10
console.log(Object.getPrototypeOf(obj) === myProto); // true

// 생성자 함수
function Person(name) {
  this.name = name;
}

// obj -> Person.prototype -> Object.prototype -> null
// 프로토타입 연결은 같지만 Person 생성자 본문은 실행하지 않음
obj = Object.create(Person.prototype);
obj.name = "Lee";
console.log(obj.name); // Lee
console.log(Object.getPrototypeOf(obj) === Person.prototype); // true
```

`Object.create`는 첫 번째 인수로 전달한 객체를 직접 프로토타입으로 하는 새 객체를 생성한다. 따라서 생성 시점에 직접 상속을 구성할 수 있다.

- `new` 연산자 없이도 객체를 생성할 수 있다.
- 프로토타입을 지정하여 객체를 생성할 수 있다.
- 객체 리터럴로 만든 객체도 프로토타입으로 지정해 상속받을 수 있다.

`Object.prototype`을 상속하는 객체는 그 빌트인 메서드를 사용할 수 있지만, `null` 프로토타입 객체는 상속하지 않으므로 별도로 호출해야 한다.

**예제 19-52**

```js
const obj = { a: 1 };

obj.hasOwnProperty("a"); // true
obj.propertyIsEnumerable("a"); // true
```

프로토타입이 `null`인 객체는 `Object.prototype`의 빌트인 메서드를 상속받지 않는다.

**예제 19-53**

```js
// 프로토타입 null 객체, 즉 프로토타입 체인의 종점에 위치하는 개체를 생성
const obj = Object.create(null);
obj.a = 1;

console.log(Object.getPrototypeOf(obj) === null); // true

// obj는 Object.prototype의 빌트인 메서드를 사용할 수 없음
try {
  console.log(obj.hasOwnProperty("a"));
} catch (error) {
  console.log(error.name); // TypeError
}
```

필요하다면 `Object.prototype.hasOwnProperty.call`로 간접 호출할 수 있다. 최신 환경에서는 `Object.hasOwn`을 사용할 수도 있다.

**예제 19-54**

```js
// 프로토타입이 null인 객체, 즉 프로토타입 체인의 종점에 위치하는 개체를 생성
const obj = Object.create(null);
obj.a = 1;

// console.log(obj.hasOwnProperty('a')); // TypeError
// Object.prototype의 빌트인 메서드는 객체로 직접호출하지 않음
console.log(Object.prototype.hasOwnProperty.call(obj, "a")); // true
```

## 19.11.2 객체 리터럴 내부에서 `__proto__`를 사용한 직접 상속

객체 리터럴의 `__proto__: prototype` 문법은 객체 생성 시 프로토타입을 지정하는 문법이다. `obj.__proto__` 접근자로 프로토타입을 조회하거나 변경하는 것과 구분한다.

**예제 19-55**

```js
const myProto = { x: 10 };

// 객체 리터럴에 의해 객체를 생성하면서 프로토타입을 지정하여 직접 상속받을 수 있음
const obj = {
  y: 20,
  // 객체를 직접 상속받음
  // obj -> myProto -> Object.prototype -> null
  __proto__: myProto,
};
/* 위 코드는 아래와 동일
const obj = Object.create(myProto, {
  y: { value: 20, writable: true, enumerable: true, configurable: true }
});
*/
console.log(obj.x, obj.y); // 10 20
console.log(Object.getPrototypeOf(obj) === myProto); // true
```
