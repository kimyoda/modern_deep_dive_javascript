## 20.4 함수 단위로 strict mode를 적용하는 것도 피하자

함수 단위로도 strict mode를 적용할 수 있다. 그러나 바깥 코드가 비엄격 모드인 상태에서 일부 함수에만 엄격 모드를 적용하면 서로 다른 규칙이 혼재해 예기치 않은 문제가 생길 수 있다.

**예제 20-07**

```js
(function () {
  // non-strict mode
  var let = 10; // 비엄격 모드에서는 허용됨
  function foo() {
    "use strict";

    let = 20; // SyntaxError: strict mode 예약어 사용
  }
  foo();
})();
```

이 예제의 `let`은 비엄격 모드에서는 식별자로 사용할 수 있지만, strict mode에서는 예약어이므로 함수 안의 `let = 20`이 문법 오류를 일으킨다.

> **주의:** 이 코드는 **의도적으로 `SyntaxError`를 발생시키는 예제**다. 문법 분석 단계에서 실패하므로 바깥의 `var let = 10`도 실행되지 않는다.

기존 일반 스크립트를 엄격 모드로 전환할 때는 즉시 실행 함수(IIFE)로 스크립트 단위의 코드를 묶어 일관되게 적용할 수 있다. ES 모듈은 기본적으로 엄격 모드이므로 이 방식이 반드시 필요한 것은 아니다.
