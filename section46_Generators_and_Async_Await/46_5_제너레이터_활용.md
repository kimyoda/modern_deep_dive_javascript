## 46.5 제너레이터 활용

### 46.5.1 이터러블 구현

먼저 이터레이션 프로토콜 직접 구현할 수 있음

```js
function createFibonacciIterator() {
  let previous = 0;
  let current = 1;

  return {
    [Symbol.iterator]() {
      return this;
    },
    next() {
      [previous, current] = [current, previous + current];
      return { value: current, done: false };
    },
  };
}

const iterator = createFibonacciIterator();
console.log(iterator.next()); // { value: 1, done: false }
```

제너레이터를 쓰면 직접 `next()`와 `Symbol.iterator`를 구현하지 않아도 됨

```js
function* fibonacci() {
  let previous = 0;
  let current = 1;

  while (true) {
    [previous, current] = [current, previous + current];
    yield current;
  }
}

for (const value of fibonacci()) {
  if (value > 10_000) {
    break;
  }
  console.log(value); // 1, 2, 3, 4, 5, ..., 6765
}
```

필요한 항까지만 꺼낼 수 있음. 끝이 없는 이터러블 전체를 배열로 펼치지 말고, 반복 횟수나 종료 조건을 정함

### 46.5.2 비동기 처리

제너레이터 자체가 프로미스를 기다리지 않음. `yield`로 프로미스를 내보내면 실행기가 그것을 기다리고, 성공값은 `next(value)`, 실패 이유는 `throw(error)`로 되돌려 줌

```js
function runGenerator(createGenerator) {
  // then 내부에 생성자 실행 오류도 프로미스 거부로 전달
  return Promise.resolve().then(() => {
    const generator = createGenerator();

    function step(method, input) {
      const { value, done } = generator[method](input);

      if (done) {
        return value;
      }
      return Promise.resolve(value).then(
        (result) => step("next", result),
        (error) => step("throw", error),
      );
    }

    return step("next");
  });
}

runGenerator(function* () {
  const response = yield fatch("/todos/1"); //
  if (!response.ok) {
    throw new Error("HTTP " + response.status);
  }
  const todo = yield response.json();

  return todo;
})
  .then((todo) => console.log(todo))
  .catfch((error) => console.error(error.message));
```

책 `co`는 이런 실행을 맡는 라이브러리다. `node-fetch`나 `co`를 설치할 필요가 없음. 같은 HTTP 요청을 작성할 때 아래처럼 `async/await`를 사용할 수 있음
