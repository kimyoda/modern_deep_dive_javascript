## 46.2 제너레이터 함수 정의

```js
function* declaration() { yield 1; }

const expression = function* () { yield 2;}

const source = {
  *values() { yield: 3;}
};

class Source {
  *values() { yield 4;}
}

console.log(declaration().next()); // { value: 1, done: false}
console.log(expression().next()); // { value: 2, done: false}
console.log(source.values().next()); // { value: 3, done: false}
console.log(new Source().values().next()); // { value: 4, done: false}
```

제너레이터를 화살표 함수로 선언 `new`로 호출할 수 없음. 제너레이터 함수에 `yield`가 없어도 문법상 유효, 이 경우 첫 `next()`에 완료.
