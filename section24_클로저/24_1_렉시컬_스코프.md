# 24.1 렉시컬 스코프

- 상위 스코프는 **함수를 어디서 호출했는가**가 아닌 **어디에 정의했는지**로 결정된다(정적 스코프).
- 렉시컬 환경의 "외부 렉시컬 환경에 대한 참조"에 무엇을 저장할지가 정의 위치로 결정된다.

## 중첩 함수가 외부 함수의 변수에 접근

**예제 24-01**

```js
const x = 1;

function outerFunc() {
  const x = 10;

  function innerFunc() {
    console.log(x); // 10
  }

  innerFunc();
}

outerFunc();
```

## 함수 정의 위치에 따라 접근 가능 여부가 달라짐

**예제 24-02**

```js
const x = 1;

// innerFunc는 outerFunc 내부에서 정의된 게 아니다
function outerFunc() {
  const x = 10;
  innerFunc(); // 1
}

function innerFunc() {
  console.log(x); // 1 (전역 x)
}

outerFunc();
```

## 호출 위치와 상위 스코프는 무관

**예제 24-03**

```js
const x = 1;

function foo() {
  const x = 10;
  bar(); // 호출 위치는 상위 스코프에 영향이 없음
}

function bar() {
  console.log(x); // 1
}

foo();
```

## 정의 위치와 호출 위치 비교

| 함수                | 정의된 위치      | 호출된 위치      | 상위 스코프        | 출력 |
| -------------------- | ----------------- | ----------------- | ------------------- | ----- |
| `innerFunc` (24-01) | `outerFunc` 내부 | `outerFunc` 내부 | `outerFunc` 스코프 | `10` |
| `innerFunc` (24-02) | 전역             | `outerFunc` 내부 | 전역               | `1`  |
| `bar` (24-03)       | 전역             | `foo` 내부       | 전역               | `1`  |

## 스코프 체인

| 변수 탐색 순서 | 환경                   | x의 값 |
| --------------- | ----------------------- | -----: |
| 1              | bar의 지역 환경        | 없음   |
| 2              | bar가 정의된 전역 환경 | 1      |

`foo`의 지역 변수 `x = 10`은 `bar`의 스코프 체인에 포함되지 않는다.
