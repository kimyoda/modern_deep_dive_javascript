# 41장. 타이머

> 타이머는 함수의 실행을 예약. 지정한 지연 시간은 콜백이 정확히 실행되는 시각을 보장하지 않음

## 41.1 호출 스케줄링

`run()` 지금 함수를 호출. `setTimeout(run, 1000)`은 함수 **참조**를 전달해 나중에 실행되도록 예약. 예약 함수는 기다리는 동안 호출한 코드의 실행을 막지 않음

```js
function run() {
  console.log("예약한 작업");
}

console.log("A");
setTimeout(run, 1000);
console.log("B");

// A -> B -> 예약한 작업
```

`setTimeout(run(), 1000)`을 쓰면 인수를 평가할 때 `run`이 즉시 실행. 예약 함수에 `run` 또는 `() => run ()`을 전달.

타이머 API는 ECMAScript 표준 내장 함수가 아닌 **실행 환경이 제공하는 API**. 브라우저와 Node.js 모두 비슷한 이름을 쓰나 기본 지연 시간과 반환값은 다름.
