## 40.10 이벤트 핸들러 인수전달

### 방법 1. 래퍼 함수에 호출

```js
const input = document.getElementById("username");
const message = document.getElementById("message");

function checkLength(value, min) {
  return value.length < min ? `이름은 ${min}자 입력하세요.` : "";
}

input.addEventListener("blur", (event) => {
  message.textContent = checkLength(event.currentTarget.value, 5);
});
```

등록하는 함수는 event => ...이고, blur가 발생할 때 안에서 checkLength에 값과 최소 길이 5를 전달. 이벤트 객체를 받는 함수와 실제 검증 함수를 분리한 것.

### 방법2. 핸들러를 반환하는 함수

```js
const input = document.getElementById("username");
const message = document.getElementById("message");

function createLengthHandelr(min) {
  return function (event) {
    const value = event.currentTarget.value;
    message.textContent =
      value.length < min ? `이름은 ${min}자 입력하세요.` : "";
  };
}

const handler = createLengthHandler(5);
input.addEventListener("blur", handler);
```

createLengthHadnler(5)는 등록 시 실행되난, 실제 검증은 반환된 함수가 blur 때 호출되어 실행된다. min은 클로저에 유지. 호출 결과가 실제 핸들러 함수인지 구분해야 한다
