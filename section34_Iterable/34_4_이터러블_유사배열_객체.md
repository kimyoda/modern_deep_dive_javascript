## 34.4 이터러블과 유사 배열 객체

유사 배열은 인덱스 형태의 프로퍼티와 length가 있는 값. 이터러블인지와 별개 성질

```js
const arrayLike = { 0: 1, 1: 2, 2: 3, length: 3 };
const values = [];

for (let i = 0; i < arrayLike.length; i++) {
  values.push(arrayLike[i]);
}
console.log(values); // [1, 2, 3]
console.log(Array.from(arrayLike)); // [1, 2, 3]

try {
  console.log([...arrayLike]);
} catch (error) {
  console.log(error.name); // TypeError
}

function inspectArguments() {
  return [arguments.length, typeof arguments[Symbol.iterator], [...arguments]];
}
console.log(inspectArguments(1, 2)); // [2, 'function', [1, 2]]
```

| 값                | 유사 배열 | 이터러블 |
| ----------------- | --------- | -------- |
| 일반적 배열       | O         | O        |
| 문자열            | O         | O        |
| arguments         | O         | O        |
| Set·Map           | X         | O        |
| 위 arrayLike 객체 | O         | X        |

Array.from은 유사 배열 또는 이터러블을 배열로 바꿈. 둘 다 해당하면 이터러블 경로를 사용
