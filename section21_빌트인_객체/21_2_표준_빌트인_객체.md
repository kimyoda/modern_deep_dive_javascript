## 21.2 표준 빌트인 객체

자바스크립트는 `Object`, `String`, `Number`, `Boolean`, `Symbol`, `Date`, `Math`, `RegExp`, `Array`, `Map`/`Set`, `WeakMap`/`WeakSet`, `Function`, `Promise`, `Reflect`, `Proxy`, `JSON`, `Error` 등 다양한 표준 빌트인 객체를 제공한다.
표준 빌트인에는 생성자 함수와 일반 객체 등이 포함된다. `Math`, `JSON`, `Reflect`는 생성자 함수가 아닌 일반 객체이며, `Symbol`과 `BigInt`는 `new`로 호출할 수 없는 함수다. 생성자에 따라 정적 메서드와 프로토타입 메서드가 다르다.
`String`, `Number`, `Boolean`, `Function`, `Array`, `Date` 등은 `new`와 함께 호출하여 인스턴스를 생성할 수 있다.

**예제 21-01**

```js
// String 생성자 함수에 의한 String 객체 생성
const strObj = new String("Lee"); // [String: "Lee"] (표시 형식은 환경에 따라 다름)
console.log(typeof strObj); // object

// Number 생성자 함수에 의한 Number 객체
const numObj = new Number(123); // [Number: 123] (표시 형식은 환경에 따라 다름)
console.log(typeof numObj); // object

// Boolean 생성자 함수에 의한 Boolean 객체 생성
const boolObj = new Boolean(true); // [Boolean: true] (표시 형식은 환경에 따라 다름)
console.log(typeof boolObj); // object

// Function 생성자 함수에 의한 Function 객체(함수) 생성
const func = new Function("x", "return x * x"); // anonymous 함수 생성
console.log(typeof func); // function

// Array 생성자 함수에 의한 Array 객체(배열) 생성
const arr = new Array(1, 2, 3); // [1, 2, 3]
console.log(typeof arr); // object

// RegExp 생성자 함수에 의한 RegExp 객체(정규 표현식) 생성
const regExp = new RegExp(/ab+c/i); // /ab+c/i
console.log(typeof regExp); // object

// Date 생성자 함수에 의한 Date 객체 생성
const date = new Date(); // 현재 날짜와 시각 (출력 형식과 시간대는 실행 환경에 따라 다름)
console.log(typeof date); // object
```

생성자 함수의 `prototype` 프로퍼티는 해당 생성자가 만들 인스턴스의 기본 프로토타입 객체를 가리킨다.

**예제 21-02**

```js
// String 생성자 함수에 의한 String 객체 생성
const strObj = new String("Lee"); // String { "Lee" }

// String 생성자 함수를 통해 생성한 strObj 객체의 프로토타입은 String.prototype이다
console.log(Object.getPrototypeOf(strObj) === String.prototype); // true
```

생성자 함수의 `prototype` 프로퍼티에 바인딩된 객체는 다양한 프로토타입 메서드를 제공한다. 예를 들어 `Number.prototype`의 메서드는 `Number` 인스턴스가 상속하여 사용할 수 있다. 반면 `Number.isInteger`와 같은 정적 메서드는 인스턴스를 생성하지 않고 생성자 함수에서 직접 호출한다.

**예제 21-03**

```js
// Number 생성자 함수에 의한 Number 객체 생성
const numObj = new Number(1.5); // [Number: 1.5] (표시 형식은 환경에 따라 다름)

// toFixed는 Number.prototype 프로토타입 메서드
// Number.prototype.toFixed는 지정한 소수 자릿수로 반올림한 결과를 문자열로 반환
console.log(numObj.toFixed()); // 2 (반환값은 문자열 "2")

// isInteger는 Number 정적 메서드다
// Number.isInteger는 인수가 정수인지 검사하여 결과를 불리언 값으로 반환
console.log(Number.isInteger(0.5)); // false
```
