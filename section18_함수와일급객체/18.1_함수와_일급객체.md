# 18.1 일급 객체

다음 조건을 만족하는 객체를 **일급 객체**라고 한다

1. 무명의 리터럴로 생성할 수 있다.
2. 런타임에 생성할 수 있다.
3. 변수나 자료구조에 저장할 수 있다.
4. 함수의 매개변수에 전달할 수 있다.
5. 함수의 반환값으로 사용할 수 있다.

자바스크립트의 함수는 위 조건을 모두 만족하여 **일급 객체**다.

```js
const increase = function (num) {
  return ++num;
};

const decrease = function (num) {
  return --num;
};

const predicates = {
  increase,
  decrease,
};

function makeCounter(predicate) {
  let num = 0;

  return function () {
    num = predicate(num);
    return num;
  };
}

const increaser = makeCounter(predicates.increase);

console.log(increaser());
// 1

console.log(increaser());
// 2

const decreaser = makeCounter(predicates.decrease);

console.log(decreaser());
// -1

console.log(decreaser());
// -2
```

함수가 일급 객체라는 것은 **함수를 값처럼 사용할 수 있다**는 의미다.

즉, 함수는 다음과 같은 곳에서 사용할 수 있다.

- 변수에 할당
- 객체의 프로퍼티 값으로 저장
- 배열의 요소로 저장
- 함수 호출 시 인수로 전달
- 함수의 반환값으로 사용

```js
const sayHello = function () => {
  return 'Hello';
};

const obj = {
  message: sayHello
};

function execute(fn) {
  return fn();
}

console.log(execute(obj.message));
// Hello
```

일급객체로서 함수가 가지는 큰 특징은 함수의 매개변수에 전달, 함수의 반환값으로도 사용 할 수 있다

자바스크립트에서 함수형 프로그래밍이 가능하다

함수는 객체로 프로퍼티를 가질 수 있다

일반 객체와 함수 객체는 차이가 있다

| 구분               | 일반 객체 | 함수 객체 |
| ------------------ | --------- | --------- |
| 값으로 사용        | 가능      | 가능      |
| 프로퍼티 소유      | 가능      | 가능      |
| 호출               | 불가능    | 가능      |
| 함수 고유 프로퍼티 | 없음      | 있음      |

함수는 객체지만 일반 객체와 달리 호출할 수 있다.

또한 함수 객체는 `arguments`, `caller`, `length`, `name`, `prototype` 같은 함수 고유의 프로퍼티를 가진다.
