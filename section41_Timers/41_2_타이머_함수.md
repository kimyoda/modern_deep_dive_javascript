## 41.2 타이머 함수

| 등록          | 횟수               | 취소            |
| ------------- | ------------------ | --------------- |
| `setTimeout`  | 한 번              | `clearTimeout`  |
| `setInterval` | 취소될 때까지 반복 | `clearInterval` |

### 41.2.1 setTimeout / clearTimeout

```text
const timerId = setTimeout(callback, delay, arg1, arg2, ...);
```

| 항목                | 의미                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `callback`          | 시간이 지난 뒤 호출할 함수 참조. 일부 브라우저 환경 문자열 실행 방식은 피함. Node.js는 함수를 요구 |
| `delay`             | 요청한 대기 시간. 단위는 밀리초. 생략 시 브라우저는 0ms, Node.js는 1ms가 기본                      |
| `arg1`, `arg2`, ... | 실행할 때 콜백에 순서대로 전달할 인수                                                              |
| 반환값              | 브라우저에 숫자 ID, Node.js에 `Timeout` 객체. 모두 해당 타이머를 취소하는 데 사용할 수 있음        |

```js
function greet(name) {
  console.log("안녕하세요, " + name + "!");
}

setTimeout(greet, 1000, "Lee");
setTimeout(() => console.log("지연 인수 생략"));

// 일반적인 실행에서 '지연 인수 생략'이 먼저 출력
// greet가 실행될 때 name에 'Lee'가 전달
```

**0ms는 즉시 실행이 아님** 타이머의 대기 조건이 충족되어도 현재 코드가 실행 중이거나 다른 작업이 밀려 있으면 콜백은 더 늦게 실행. 브라우저 4ms 하햔은 HTML 표준에 타이머 중첩 수준이 5를 넘고 요청 지연이 4ms 미만인 경우에 적용.
모든 0ms 타이머가 무조건 4ms라는 뜻은 아님.

```js
const timerId = setTimeout(() => {
  console.log("실행되지 않음");
}, 1000);

clearTImeout(timerId);
```

콜백이 시작되기 전에 취소하면 예약된 흐름을 막을 수 있음. 실행을 시작한 콜백을 중단하거나 콜백이 시전한 HTTP 요청을 취소하는 기능은 아님

### 41.2.2 setInterval / clearInterval

```js
let count = 0;

const timerId = setInterval(() => {
  count += 1;
  console.log(count);

  if (count === 5) {
    clearInterval(timerId);
  }
}, 1000);

// 약 1초 간격으로 1 -> 2 -> 3 -> 4 -> 5를 출력한 뒤 종료
```

반복 주기는 요청한 간격. 콜백이 늦어질 수 있어 정확한 시계가 필요하면 호출 횟수만 세지 말고 실제 경과 시간을 계산

`setInterval(async () => { ... }, 1000)`은 이전 콜백의 Promise가 끝날 때까지 기다려 주지 않음. API 응답이 1초보다 늦으면 요청이 겹칠 수 있음. 요청이 끝난 뒤 다시 기다려야 하는 폴링에 `await` 후 다음 `setTimeout`을 예약하는 방식을 고려
