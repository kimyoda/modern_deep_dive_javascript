## 31.5 패턴

### 31.5.1 문자열 검색 / 31.5.2 임의의 문자

```js
console.log(/is/.test("Is")); // false
console.log(/is/i.test("Is")); // true
console.log("abcdef".match(/.../g)); // ['abc', 'def']
console.log(/^.$/.test("�")); // false
console.log(/^.&/u.test("�")); // true
```

점은 기본적으로 줄바꿈 문자를 제외한 한 단위를 매칭. Unicode 모드에서 서로게이트 쌍을 하나의 코드 포인트로 처리할 수 있음. 점 자체를 찾으려면 `\`.를 사용

### 31.5.3 반복 검색

| 패턴    | 의미         |
| ------- | ------------ |
| A{2}    | 정확히 2회   |
| A{2, }  | 최소 2회     |
| A{1, 2} | 1~2회        |
| A+      | 1회 이상     |
| A\*     | 0회 이상     |
| A?      | 0회 또는 1회 |

```js
const text = "A AA AAA";

console.log(text.match(/A{1,2}/g)); // ['A', 'AA', 'AA', 'A']
console.log(text.match(/A{2}/g)); // ['AA', 'AA']
console.log(text.match(/A{2,}/g)); // ['AA', 'AAA']
console.log(text.match(/A+/g)); // ['A', 'AA', 'AAA']
console.log("color colour".match(/colou?r/g)); // ['color', 'colour']
```

### 31.5.4 OR 검색과 문자 클래스

| 패턴       | 의미                |
| ---------- | ------------------- |
| A\|B       | A 또는 B            |
| [AB]       | A 또는 B 한 단위    |
| [A-Z]      | 영문 대문자 범위    |
| [A-Za-z]   | 영문 대·소문자 범위 |
| [0-9]      | ASCII 숫자 범위     |
| (?:ab\|cd) | 캡처하지 않는 그룹  |

```js
console.log("A BB AAA".match(/A+|B+/g)); // ['A', 'BB', 'AAA']
console.log("ABBA".match(/[AB]+/g)); // ['ABBA']
console.log("AA Bb 12".match(/[A-Za-z]+/g)); // ['AA', 'Bb']
console.log("12,345".match(/[0-9]+/g)); // ['12', '345']
console.log("12,345".match(/[\d,]+/g)); // ['12,345']
```

`[\d,]+` 는 쉼표가 들어간 구간을 찾는 패턴.

#### 축약 문자 클래스

| 패턴 | 의미                                       |
| ---- | ------------------------------------------ |
| \d   | ASCII 숫자 0~9                             |
| \D   | ASCII 숫자가 아닌 문자                     |
| \w   | 일반적으로 영문·숫자·밑줄                  |
| \W   | \w가 아닌 문자                             |
| \s   | 공백 문자와 줄바꿈·탭 및 여러 Unicode 공백 |
| \S   | 공백이 아닌 문자                           |

```javascript
console.log("Aa_1 한글".match(/\w+/g)); // ['Aa_1']
console.log("A1B2".match(/\D+/g)); // ['A', 'B']
console.log(/^\s+/.test("\t hello")); // true
console.log(/^\p{L}+$/u.test("홍길동")); // true
```

\w를 모든 언어의 글자를 뜻하는 것으로 이해하지 않음. 공백도 일반 스페이스 하나만을 의미하지 않음

### 31.5.5 NOT / 31.5.6 시작 / 31.5.7 끝

| 위치             | 기호   | 의미                            |
| ---------------- | ------ | ------------------------------- |
| 문자 클래스 시작 | [^0-9] | 해당 집합을 제외                |
| 문자 클래스 바깥 | ^      | 입력 시작, m이면 줄 시작도 포함 |
| 문자 클래스 바깥 | $      | 입력 끝, m이면 줄 끝도 포함     |

```js
console.log("AA 12 BB".match(/[^0-9]+/g)); // ['AA ', ' BB']
console.log(/^https/.test("https://example.com")); // true
console.log(/\.html$/.test("index.html")); // true
console.log(/\.html$/.test("index.html.bak")); // false
console.log(/\d+/.test("abc123")); // true: 일부 검색
console.log(/^\d+$/.test("abc123")); // false: 전체 형식 검사
```

### 캡처 그룹과 탐욕성

```js
const match = /(?<year>\d{4})-(?<month>\d{2})/.exec("2020-07");

console.log(match[0]); // '2020-07'
console.log(match[1]); // '2020'
console.log(match.groups.month); // '07'

const html = "<b><A></b><b>B</b>";
console.log(html.match(/<.*>/g)); // ['<b>A</b><b>B</b>']
console.log(html.match(/<.*?>/g)); // ['<b>', '</b>', '<b>', '</b>']
```

수량자는 기본적으로 많이 매칭하려는 성질이 있음. 수량자 뒤의 ?는 가능한 짧게 매칭하는 형태로 바꿈. HTML 전체 구조 분석에 HTML 사용하는 등 대상 문법에 맞는 도구를 선택.
