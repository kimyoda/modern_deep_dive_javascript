# 24.2 함수 객체의 내부 슬롯 `[[Environment]]`

- 일반적인 JavaScript 함수 객체를 생성할 때, 함수가 정의된 환경에 대한 참조를 내부 슬롯 `[[Environment]]`에 저장한다.
- 전역 함수 선언문은 전역 렉시컬 환경을 기억하며, 함수 안에서 정의된 함수 표현식은 해당 함수가 정의된 렉시컬 환경을 기억한다.
- 함수가 호출되면, 새로 만든 함수 렉시컬 환경의 **외부 렉시컬 환경 참조**에 함수 객체의 `[[Environment]]` 값을 설정한다.
- 호출 위치가 달라져도 상위 스코프의 식별자를 같은 렉시컬 스코프 규칙으로 탐색한다.

> `[[Environment]]`는 명세의 내부 슬롯이며 일반 프로퍼티가 아니다. `fn['[[Environment]]']`로 내부 슬롯을 읽을 수 없다.

**예제 24-04**

```js
const x = 1;

function foo() {
  const x = 10;

  // 상위 스코프는 함수 정의 환경(위치)에 따라 결정된다
  // 함수 호출 위치와 상위 스코프는 아무런 관계가 없다
  bar();
}

// 함수 bar는 자신의 상위 스코프, 즉 전역 렉시컬 환경을 기억
function bar() {
  console.log(x);
}

foo(); // 1
```

## 함수 객체와 `[[Environment]]`

| 함수객체 | 저장한 상위 환경 | 호출 위치 변경 |
| --------- | ----------------- | --------------- |
| foo      | 전역 렉시컬 환경 | 변경되지 않음  |
| bar      | 전역 렉시컬 환경 | 변경되지 않음  |

## `bar` 실행 중 컨텍스트 스택

| 스택 위치 | 실행 중인 컨텍스트 | 변수 탐색 역할                                 |
| ---------- | ------------------- | ----------------------------------------------- |
| 위        | bar                | bar 지역 환경부터 탐색                         |
| 중간      | foo                | bar를 호출했지만 bar의 상위 스코프가 되지 않음 |
| 아래      | 전역               | bar의 상위 환경이며 x = 1을 제공               |

호출 스택은 함수의 호출 및 복귀 순서를 나타내고, 스코프 체인은 식별자를 탐색하는 경로를 나타낸다.

## 함수 호출 시 평가 순서

1. 함수 실행 컨텍스트 생성
2. 함수 렉시컬 환경 생성
3. 함수 환경 레코드 생성
4. `this` 바인딩
5. 외부 렉시컬 환경 참조 결정 ← 함수 객체의 `[[Environment]]` 값을 참조한다.
