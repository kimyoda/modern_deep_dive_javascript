## 31.1 정규 표현식

일정한 규칙을 가진 문자열의 집합을 표현하는 패턴. RegExp는 JavaScript의 정규 표현식 객체. 문자열 검색·추출·치환·분리에 활용.

```js
const pattern = /^010-\d{4}-\d{4}$/;

console.log(pattern.test("010-1234-5678")); // true
console.log(pattern.test("010-1234-567팔")); // false
console.log(pattern.test("전화: 010-1234-5678")); // false
```
