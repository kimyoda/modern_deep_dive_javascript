# 📘 모던 자바스크립트 Deep Dive 정리 프로젝트

『모던 자바스크립트 Deep Dive』를 읽으며 자바스크립트의 핵심 개념을  
**직접 정리하고 문서화하는 프로젝트**입니다.

---

## 🧠 왜 이걸 하는가?

- 단순히 읽는 데서 끝나는 것이 아니라, **직접 쓰고 정리하며 개념을 내 것으로 만들기 위해** 시작했습니다.
- 자바스크립트를 기초부터 깊이 있게 정리하고, **실제로 설명하고 활용할 수 있는 수준까지 도달**하는 것이 목표입니다.

## 🤖 Codex 활용

이 프로젝트는 학습 내용을 정리하고 보완하는 과정에서 **OpenAI의 Codex**를 활용합니다.

- 직접 작성한 내용을 바탕으로 **문서 구조와 설명을 정리**합니다.
- 이해가 부족하거나 추가 설명이 필요한 개념에 **보충 내용을 추가**합니다.
- 개념을 구체적으로 이해할 수 있도록 **예시 코드와 활용 사례를 추가하고 개선**합니다.

AI가 제안한 내용은 도서와 직접 실행한 결과를 바탕으로 검토하고,  
**내가 이해한 언어로 재정리하는 것**을 원칙으로 합니다.
