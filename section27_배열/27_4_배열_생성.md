## 27.4 배열 생성

### 27.4.1 배열 리터럴

```js
const empty = [];
const numbers = [1, 2, 3];
const sparse = [1, , 3];

console.log(empty.length); // 0
console.log(numbers.length); // 3
console.log(sparse.length); // 3
console.log(Object.hasOwn(sparse, 1)); // false
```

요소를 생략하면 빈 슬롯이 생김. 일반적인 목록을 만들 때 의도하지 않은 빈 슬롯을 피함

### 27.4.2. `Array` 생성자 함수

**인수 하나가 숫자면 요소가 아니라 길이로 해석**

```js
console.log(Array().length); // 0
console.log(Array(3).length); // 3
console.log(Object.keys(Array(3))); // []
console.log(Array(1, 2, 3)); // [1, 2, 3]
console.log(Array("3")); // ['3']
console.log(new Array(3).length); // 3

try {
  Array(-1);
} catch (error) {
  console.log(error.name); // RangeError
}
```

`Array`는 `new` 없이 호출해도 배열을 만듬. 모든 생성자 함수가 이렇게 동작하지 않음

### 27.4.3 `Array.of`

인수 개수나 숫자 여부와 관계없이 **전달된 인수를 요소로** 갖는 배열을 만듬

```js
console.log(Array.of(3)); // [3]
console.log(Array.of(1, 2, 3)); // [1, 2, 3]
console.log(Array.of()); // []
```

### 27.4.4 `Array.from`

유사 배열 객체 또는 이터러블을 배열로 변환. 두 번째 인수로 매핑 함수를 전달할 수 있음

```js
console.log(Array.from({ 0: "a", 1: "b", length: 2 })); // ['a', 'b']
console.log(Array.from("Hello")); // ['H', 'e', 'l', 'l', 'o']
console.log(Array.from({ length: 3 })); // [undefined, undefined, undefined]
console.log(Array.from({ length: 3 }, (_, index) => index)); // [0, 1, 2]
```

| 구분           | 특징                            | 예시                              |
| -------------- | ------------------------------- | --------------------------------- |
| 유사 배열 객체 | 인덕세 형태 프로퍼티와 `length` | `{ 0: 'a', length: 1 }`           |
| 이터러블       | 반복자 프로토콜로 순회 가능     | 배열, 문자열, `Set`, `Map`        |
| 둘 다 해당     | 두 성질을 함께 가짐             | 베열, 현대 JavaScript `arguments` |

유사 배열이라고 자동으로 `for...of`나 Spread를 사용할 수 있는 것은 아님. `Array.from`은 순수한 유사 배열 객체도 처리할 수 있음
