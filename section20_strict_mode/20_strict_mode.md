# 20장 strict mode

## 학습 목표와 실행 환경

- **strict mode는 실수를 방지하기 위해 일부 문법과 실행 동작을 더 엄격하게 제한하는 규칙이다.**
- 선언하지 않은 식별자에 대입, `delete 식별자`, 중복 매개변수, `with` 문 사용 시 동작을 구분한다.
- 일반 함수 호출에서 `this`의 값과 매개변수·`arguments` 객체의 연결 차이를 확인한다.
- ESLint는 정적 분석 도구이며 strict mode와 동일한 기능은 아니다.

| 코드 종류                        | strict mode                             |
| -------------------------------- | --------------------------------------- |
| 브라우저 일반 `<script>`         | 기본적으로 비엄격 모드이며, 지시문 영역에 `"use strict";`를 작성하면 적용된다. |
| ES 모듈 (`.mjs`, `type="module"`) | 별도의 지시문 없이 자동 적용된다. |
| 클래스 본문                      | 별도의 지시문 없이 자동 적용된다. |
| Node.js CommonJS (`.cjs`)       | 일반적으로 자동으로 strict mode가 적용되지 않는다. |
