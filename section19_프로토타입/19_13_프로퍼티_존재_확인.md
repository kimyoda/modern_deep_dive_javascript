# 19.13 프로퍼티 존재 확인

## 19.13.1 in 연산자

`in` 연산자는 객체 또는 그 프로토타입 체인에 특정 프로퍼티가 존재하는지 확인한다.

**`in` 연산자 문법 (원본 표기: 예제 18-02)**

```text
/**
 * key: 프로퍼티 키를 나타내는 문자열
 * object: 객체로 평가되는 표현식
*/
key in object
```

**예제 19-59**

```js
const person = {
  name: "Lee",
  address: "Seoul",
};

// person 객체에 name 프로퍼티가 존재
console.log("name" in person); // true
// person 객체에 address 프로퍼티가 존재
console.log("address" in person); // true
// person 객체에 age 프로퍼티가 존재
console.log("age" in person); // false
```

`in` 연산자는 객체 자신의 프로퍼티뿐 아니라 상속받은 프로퍼티도 확인한다. `person`은 `toString`을 고유 프로퍼티로 갖지 않지만, 다음 표현식은 `true`다.

**예제 19-60**

```js
console.log("toString" in person); // true
```

`in` 연산자가 `person`의 프로토타입 체인에서 `toString`을 찾기 때문이다. `toString`은 `Object.prototype`에 정의된 메서드다.

ES6부터는 `Reflect.has` 메서드로도 같은 종류의 존재 여부 검사를 할 수 있다.

**예제 19-61**

```js
const person = { name: "Lee" };

console.log(Reflect.has(person, "name")); // true
console.log(Reflect.has(person, "toString")); // true
```

## 19.13.2 `Object.prototype.hasOwnProperty` 메서드

`Object.prototype.hasOwnProperty` 메서드로 객체가 특정 프로퍼티를 직접 소유하는지 확인할 수 있다.

**예제 19-62**

```js
console.log(person.hasOwnProperty("name")); // true
console.log(person.hasOwnProperty("age")); // false
```

`hasOwnProperty`는 인수로 전달한 프로퍼티 키가 객체 자신의 고유 프로퍼티이면 `true`, 상속된 프로퍼티이면 `false`를 반환한다.

**예제 19-63**

```js
console.log(person.hasOwnProperty("toString")); // false
```

### Object.hasOwn을 사용한 고유 프로퍼티 검사

`Object.hasOwn`은 프로토타입이 `null`인 객체에도 사용할 수 있다. 객체가 `hasOwnProperty`라는 이름의 프로퍼티를 직접 소유하더라도 안전하게 동작한다.

```js
const obj = Object.create(null);
obj.name = "Lee";

console.log(Object.hasOwn(obj, "name")); // true
console.log(Object.hasOwn(obj, "toString")); // false
```

| 방법                        | 고유 프로퍼티 | 상속 프로퍼티 |
| --------------------------- | ------------- | ------------- |
| `'key' in obj`              | 검사          | 검사          |
| `Reflect.has(obj, 'key')`   | 검사          | 검사          |
| `Object.hasOwn(obj, 'key')` | 검사          | 검사하지 않음 |

값이 `undefined`인 프로퍼티도 존재할 수 있으므로 `obj.key !== undefined`만으로 존재 여부를 판정해서는 안 된다.
