# 26장. ES6 함수의 추가 기능

> **함수 역할에 맞는 문법을 선택**
> 객체의 동작은 메서드로, 바깥의 `this`를 유지할 콜백은 화살표 함수로, 가변 인수는 Rest 파라미터로 표현한다.

## 26.1 함수 구분

### 1. 일반 함수는 여러 방식으로 호출할 수 있다

일반적인 함수 선언문, 함수 표현식으로 만든 함수는 일반 호출, 생성자 호출, 객체의 메서드 호출에 사용할 수 있다

```js
function foo() {
  return 1;
}

const obj = { foo };

console.log(foo()); // 1
console.log(obj.foo()); // 1
console.log(new foo() instanceof foo); // true
```

`new foo()`에서 반환한 숫자 `1`은 무시되고 생성된 인스턴스가 반환된다. 일반 함수가 객체의 프로퍼티에 저장되었다고 해서 생성자 기능이 사라지지 않음

### 2. ES6에서 역할별 문법을 구분

| 구분                      | 일반 함수         | 메서드                | 화살표 함수                     |
| ------------------------- | ----------------- | --------------------- | ------------------------------- |
| 예시                      | `function f() {}` | `{ f() {} }`          | `const f = () => {}`            |
| 일반 호출                 | 가능              | 가능                  | 가능                            |
| `new` 호출                | 가능              | 불가능                | 불가능                          |
| 자체 `prototype` 프로퍼티 | 있음              | 없음                  | 없음                            |
| 자체 `this` 바인딩        | 있음              | 있음                  | 없음                            |
| 자체 `arguments`          | 있음              | 있음                  | 없음                            |
| `[[HomeObject]]`          | 없음              | 있음                  | 없음                            |
| `super.prop`              | 직접 사용 불가    | 해당 문맥에 사용 가능 | 유효한 바깥 문맥의 `super` 참조 |

> **표의 범위:** 일반 함수는 `async`, 제너레이터, 바인딩된 함수를 제외한 보통의 함수, 메서드는 일반 축약 메서드다. 클래스의 `constructor`는 클래스에서 인스턴스 초기화를 담당하는 별도 문법으로 이해

| 용어            | 의미                                                          |
| --------------- | ------------------------------------------------------------- |
| callable        | 내부 메서드 `[[Call]]`을 통해 호출할 수 있음                  |
| constructor     | 내부 메서드 `[[Construct]]` 를 통해 인스턴스를 생성할 수 있음 |
| non-constructor | 함수처럼 호출할 수 있지만 `new`로는 생성할 수 없다            |

**`prototype` 프로퍼티 유무만으로 모든 함수의 생성자 여부를 판단하면 안 된다**

| 예외                                 | 자체 `prototype` | `new` 호출 |
| ------------------------------------ | ---------------- | ---------- |
| 제너레이터 함수·제너레이터 메서드    | 있음             | 불가능     |
| 생성자 함수를 `bind`로 바인딩한 함수 | 없음             | 가능       |
| 화살표 함수                          | 없음             | 불가능     |

또한 함수의 `.prototype` 프로퍼티와 함수 객체의 내부 `[[Prototype]]`은 다름. 화살표 함수도 보통 `Function.prototype`을 상속하여 `call`, `apply`, `bind`를 사용할 수 있음
