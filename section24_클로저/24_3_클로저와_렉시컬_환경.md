# 24.3 클로저와 렉시컬 환경

- 외부 함수보다 **중첩 함수가 더 오래 살아남는** 경우, 중첩 함수는 이미 종료된 외부 함수의 변수를 참조할 수 있다. 이것이 클로저의 대표적인 사용 사례다.
- 외부 함수의 실행 컨텍스트가 스택에서 제거돼도, **도달 가능한 클로저가 사용하는 상위 환경의 바인딩은 계속 사용할 수 있다.**

- 상위 스코프의 식별자를 참조하는 함수는 외부 함수의 실행이 끝난 뒤에도 해당 식별자에 접근할 수 있다.

> 두 항목을 일반적인 클로저 정의의 필수 조건으로 외우지는 않음. 아래 24-07처럼 외부 함수 실행 도중 호출하는 중첩 함수도 렉시컬 환경에 접근하는 클로저로 설명

## 클로저의 기본 형태

**예제 24-05**

```js
const x = 1;

// 1
function outer() {
  const x = 10;
  const inner = function () {
    console.log(x);
  };
  return inner;
}

// outer 함수를 호출하면 중첩 함수 inner를 반환한다.
// outer 함수의 실행 컨텍스트는 실행 컨텍스트 스택에서 제거된다
const innerFunc = outer(); // 2
innerFunc(); // 3. 10 출력
```

## 단계별 렉시컬 환경 변화

| 단계              | 실행 컨텍스트                  | 환경과 참조                         |
| ------------------ | ------------------------------- | ------------------------------------ |
| 1. outer 생성     | 바깥 코드 실행 중              | outer가 자신이 정의된 환경을 기억   |
| 2. outer 호출     | outer 컨텍스트가 스택에 추가   | x = 10을 담은 호출 환경 생성        |
| 3. inner 생성     | outer 실행 중                  | inner가 해당 outer 호출 환경을 기억 |
| 4. outer 반환     | outer 컨텍스트가 스택에서 제거 | 반환된 inner를 innerFunc가 보관     |
| 5. innerFunc 호출 | inner 컨텍스트가 스택에 추가   | 상위 환경의 x를 읽어 10 출력        |

## 가비지 컬렉션과 참조 관계

| 참조를 보관하는 곳          | 참조 대상              | 의미                              |
| ---------------------------- | ----------------------- | ---------------------------------- |
| innerFunc 변수              | 반환된 inner 함수 객체 | 이후에 함수를 호출할 수 있음      |
| inner의 [[Environment]]     | outer 호출의 환경      | x = 10 바인딩을 사용할 수 있음    |
| outer 호출의 외부 환경 참조 | 전역 환경              | 상위 식별자 탐색을 이어갈 수 있음 |

## 상위 지역 변수를 사용하지 않는 함수

**예제 24-06**

```html
<!DOCTYPE html>
<html>
  <body>
    <script>
      function foo() {
        const x = 1;
        const y = 2;

        // 일반적으로 클로저라고 하지 않음
        function bar() {
          debugger;
          // 상위 스코프의 식별자를 참조하지 않음
        }
        return bar;
      }
      const bar = foo();
      bar();
    </script>
  </body>
</html>
```

## 외부 함수 실행 중에 사용하는 클로저

**예제 24-07**

```html
<!DOCTYPE html>
<html>
  <body>
    <script>
      function foo() {
        const x = 1;

        // bar는 외부 변수 x를 사용하는 클로저로 설명
        // 예제에서 반환하지 않아 외부 함수 종료 후 사용을 보여주지 않음
        function bar() {
          debugger;
          // 상위 스코프의 식별자를 참조
          console.log(x);
        }
        bar();
      }
      foo();
    </script>
  </body>
</html>
```

## 외부 함수 종료 후에도 사용하는 클로저

**예제 24-08**

```html
<!DOCTYPE html>
<html>
  <body>
    <script>
      function foo() {
        const x = 1;
        const y = 2;

        // 함수 bar는 외부 함수의 실행이 끝난 뒤에도 유지되어, 상위 스코프 식별자를 참조
        function bar() {
          debugger;
          console.log(x);
        }
        return bar;
      }

      const bar = foo();
      bar();
    </script>
  </body>
</html>
```

## 예제 비교

| 예제  | 외부 지역 변수 | 외부 함수 종료 후 호출 |
| ------ | --------------- | ----------------------- |
| 24-06 | 사용하지 않음  | 호출                   |
| 24-07 | x를 사용       | 호출하지 않음          |
| 24-08 | x를 사용       | 호출                   |

> DevTools Closure 항목 표시 여부나 `x`, `y`가 보이는 방식은 브라우저, 최적화, 디버깅 상태에 따라 다를 수 있음

## 용어 정리

| 용어      | 의미                                                                                |
| ---------- | ------------------------------------------------------------------------------------ |
| 자유 변수 | 클로저가 참조하는 상위 스코프의 변수                                                |
| 닫혀 있다 | 함수가 자유 변수에 대해 닫혀 있다. 즉, 함수와 그 렉시컬 환경이 연결되어 있다는 의미 |
