## 39.9 DOM 표준

DOM ECMAScript 자체 표준 빌트인이 아님. 문서의 노드·트리·이벤트 등을 다루는 플랫폼 표준

| 표준                   | 주로 다루는 범위                        |
| ---------------------- | --------------------------------------- |
| ECMAScript             | JavaScript 언어·기본 객체               |
| WHATWG DOM             | 노드·트리·이벤트 등                     |
| WHATWG HTML            | HTML 요소·문서·폼 등의 동작             |
| CSSOM 및 관련 CSS 표준 | 스타일시트·스타일 선언·계산된 스타일 등 |

DOM Level 1~4는 역사적인 표준화 단계를 이해할 때 참고. DOM을 고정된 Level 4 마지막 버전으로 이해하기보다 지속적으로 갱신되는 WHATWG DOM Living Standard를 기준으로 확인

## 질문, 답변

### 1. DOM은 무엇인지

- 문서를 노드 객체의 트리로 표현하고 조작하는 인터페이스

### 2. Element, Text 관계

- 텍스트는 요소의 자식 노드로 존재할 수 있음

### 3. Attr 부모 요소는 parentNode로 찾는 지

- 아님. parentNode는 null이고 ownerElement로 찾음

### 4. input 객체가 Node 기능을 사용할 수 있는지

- HTMLInputElement에 Node·EventTarget으로 이어지는 상속 체인 때문

### 5. getElementById 검색 실패 결과

- null이다

### 6. getElementsByClassName('a b')의 조건

- a와 b 클래스를 모두 가진 요소

### 7. querySelector와 querySelectorAll 차이

- 첫 요소 또는 null / 모든 일치 요소를 담은 static NodeList

### 8. matches 어떤 값을 반환하는 지

- 해당 요소가 선택자와 일치하는지 boolean으로 반환

### 9. HTMLCollection 순회하고 검색 조건을 바꾸나

- live 목록이 즉시 달라져 일부 요소를 건너뛸 수 있음

### 10. querySelectorAll과 childNodes는 둘 다 static인지

- 아님. 앞은 static, 뒤는 live

### 11. static NodeList 노드도 불변인지

- 아님. 목록 구성은 고정되나 참조한 노드는 변경 가능.

### 12. childNodes와 children차이

- 모든 자식 노드 / 자식 요소만 포함

### 13. hasChildNodes가 true면 자식 요소도 있는지

- 아님. 공백 Text만 있어도 true

### 14. nodeType 1·3·9는 무엇인지

- Element·Text·Document

### 15. Element의 nodeValue

- null

### 16. textContent에 HTML 태그를 대입

- HTML로 파싱하지 않고 텍스트로 처리

### 17. innerHTML은 대상 요소 자체의 태그도 반환하는 지

- 자식들의 HTML 표현을 반환

### 18. 기존 자식 끝에 HTML을 넣고 유지

- insertAdjacentHTML('beforeend', html)을 사용할 수 있음

### 19. createElement만으로 화면에 보이는 지

- 아님. 적절한 문서 트리에 삽입

### 20. Fragment 삽입 후 Fragment 상태

- 자식들이 부모로 이동하여 비어 있음. 객체는 남음

### 21. insertBefore 기준 노드는

- 호출 대상의 직접 자식 또는 null이어야 한다

### 22. 기존 노드를 appendChild하면

- 복사하지 않고 새 위치로 이동

### 23. cloneNode(true)가 복사하지 않는 정보는

- addEventListener로 등록한 이벤트 리스너

### 24. replaceChild 인수 순서

- 새 노드, 기존 자식 노드

### 25. removeChild 반환값

- 제거한 노드며 다시 삽힙할 수도 있음

### 26. input의 value와 defaultValue 차이

- 현재 값 / value 어트리뷰트와 연결된 기본값

### 27. data-user-id는 dataset에서 어떻게 접근하는 지

- dataset.userId로 접근하며 ㄱ밧은 문자열

### 28. className과 classList차이는

- 전체 클래스 문자열 / 개별 클래스 토큰 조작
