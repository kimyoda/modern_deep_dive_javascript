# 19장 프로토타입

## 체크

- **상속은 프로퍼티를 전부 복사하는 것이 아니라, 프로토타입 체인을 통해 찾아 사용하는 방식이다.**
- `[[Prototype]]`, 생성자 함수의 `prototype`, 프로토타입의 `constructor`를 구분한다.
- 프로퍼티 읽기, 대입, 삭제에서 고유 프로퍼티와 상속 프로퍼티가 어떻게 다르게 처리되는지 확인한다.
- `instanceof`는 기본적으로 현재 프로토타입 체인을 검사하며, 객체의 생성 이력을 보장하지 않는다.
- `in`, `Object.hasOwn`, `for...in`, `Object.keys`의 검사·열거 범위를 비교한다.

| 관계 | 의미 | 코드 |
| --- | --- | --- |
| 객체의 `[[Prototype]]` | 객체가 상속하는 상위 객체 또는 `null` | `Object.getPrototypeOf(me)` |
| `Person.prototype` | `new Person()`으로 생성한 객체가 기본적으로 상속할 객체 | `Object.getPrototypeOf(me) === Person.prototype` |
| `Person.prototype.constructor` | 기본 프로토타입에 존재하며 생성자를 가리키는 일반 프로퍼티 | `Person.prototype.constructor === Person` |
| 함수 객체 `Person` 자신의 프로토타입 | 함수 객체가 상속하는 객체 | `Object.getPrototypeOf(Person) === Function.prototype` |

## 장 도입

JavaScript는 명령형, 함수형, 프로토타입 기반 객체지향 프로그래밍 등 여러 프로그래밍 패러다임을 지원하는 언어다. 특히 **프로토타입 기반의 객체지향 프로그래밍 언어**라는 특징이 있다.

### 클래스

클래스는 ES6에서 도입되었다. 클래스도 함수이며 프로토타입 기반 상속을 사용한다. 다만 추가적인 규칙과 기능이 있으므로 생성자 함수의 단순한 별칭이라고 볼 수 없다. 클래스는 생성자 함수보다 엄격하며, 생성자 함수에는 없는 기능도 제공한다.

JavaScript의 값은 원시 값과 객체로 구분한다. 원시 타입 값을 제외한 나머지 값(함수, 배열, 정규 표현식 등)은 모두 객체다.
