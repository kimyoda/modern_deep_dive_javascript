## 34.3 for...of 문

```js
const values = [];
for (const item of [1, 2, 3]) {
  values.push(item);
}
console.log(values); // [1, 2, 3]

// 핵심 순회 과정 직접 표현 코드
const iterator = [1, 2, 3][Symbol.iterator]();
const manual = [];
while (true) {
  const result = iterator.next();
  if (result.done) {
    break;
  }
  manual.push(result.value);
}
console.log(manual); // [1, 2, 3]
```

next, done, value 관계

| 비교          | for...in                           | for...of                   |
| ------------- | ---------------------------------- | -------------------------- |
| 대상          | 객체의 열거 가능한 문자열 프로퍼티 | 이터러블                   |
| 읽는 값       | 프로퍼티 키                        | 이터레이터가 제공하는 값   |
| 상속 프로퍼티 | 포함할 수 있음                     | 이터레이터 구현에 따름     |
| 심벌 키 열거  | 제외                               | 키 열거 자체가 목적이 아님 |
