## 46.3 제너레이터 객체

제너레이터 객체는 `[Symbol.iterator]()`를 제공하는 **이터러블**인 동시에, `next()`로 `{ value, done}`을 반환하는 **이터레이터**다. `[Symbol.iterator]()`는 같은 객체를 반환

| 메서드          | 동작                                                                                    |
| --------------- | --------------------------------------------------------------------------------------- |
| `next(value)`   | 다음 `yield`, `return`, 또는 함수 끝까지 실행                                           |
| `return(value)` | 중지된 곳에 반환을 전달. 보통 `{ value, done: true}` 로 종료                            |
| `throw(error)`  | 중지된 곳에 예외를 전달. 내부 `catch`가 처리할 수 있고, 처리하지 않으면 호출자에게 던짐 |

```js
function* values() {
  try {
    yield 1;
    yield 2;
  } catch (error) {
    yield error.message;
  }
}

const first = values();
console.log(first[Symbol.iterator]() === frist); // true
console.log(first.next()); // { value: 1, done: false}
console.log(first.return("종료")); // { value: '종료', done: true }

const second = values();
second.next();
console.log(second.throw(new Error("실패"))); // { value: '실패', done: false }
console.log(second.next()); // { value: undefined, done: true }
```

`return()`을 호출해 `finally` 내부에 `yield`가 있으면 거기서 한 번 더 멈출 수 있음. `throw()`도 내부에 예외를 잡아 `yield` 하면 계속 진행할 수 있으
