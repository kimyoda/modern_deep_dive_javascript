## 19.1 객체지향 프로그래밍

객체지향 프로그래밍은 객체의 집합으로 프로그램을 표현하려는 프로그래밍 패러다임이다.

실체는 다양한 특징과 성질을 나타내는 속성으로 구별할 수 있다. 예를 들어 사람은 이름, 주소, 성별, 나이, 신장, 체중 등 여러 속성을 갖는다. 이름이 특정 값이고, 성별이 남성이며, 나이가 30세인 사람과 같이 속성을 구체적으로 표현하면 다른 사람과 구별할 수 있다.

프로그램을 구현할 때 위 속성 중 **이름과 주소**에만 관심이 있다고 가정할 수 있다. **추상화**란 다양한 속성 중 프로그램에 필요한 속성만 간추려 표현하는 것이다.

**예제 19-01**

```js
// 이름과 주소 속성을 갖는 객체
const person = {
  name: "Lee",
  address: "Seoul",
};

console.log(person); // { name: 'Lee', address: 'Seoul' }
```

프로그래머는 이름과 주소 속성으로 표현된 `person` 객체를 다른 객체와 구별하여 인식할 수 있다. 이처럼 **여러 개의 값을 하나의 단위로 구성한 복합적인 자료구조**를 객체라고 한다.

객체지향 프로그래밍은 객체의 집합으로 프로그램을 표현한다. 이번에는 원이라는 개념을 객체로 만들어 보자. 반지름은 원의 상태를 나타내는 데이터이고, 지름·둘레·넓이를 구하는 것은 원의 동작이다.

**예제 19-02**

```js
const circle = {
  radius: 5, // 반지름

  // 원의 지름: 2r
  getDiameter() {
    return 2 * this.radius;
  },

  // 원의 둘레: 2πr
  getPerimeter() {
    return 2 * Math.PI * this.radius;
  },

  // 원의 넓이: πr²
  getArea() {
    return Math.PI * this.radius ** 2;
  },
};

console.log(circle); // { radius: 5, getDiameter: [Function], getPerimeter: [Function], getArea: [Function] }

console.log(circle.getDiameter());  // 10
console.log(circle.getPerimeter()); // 31.41592...
console.log(circle.getArea());      // 78.539816...
```

객체지향 프로그래밍은 **객체의 상태를 나타내는 데이터**와 **그 데이터를 조작하는 동작**을 하나의 논리적인 단위로 묶어 생각한다.

- 상태를 나타내는 데이터는 **프로퍼티(property)**라고 한다.
- 상태를 조작하는 동작은 **메서드(method)**라고 한다.

따라서 객체는 상태 데이터와 동작을 하나로 묶은 복합적인 자료구조다.
