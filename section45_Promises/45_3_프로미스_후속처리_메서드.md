## 45.3 프로미스 후속 처리 메서드

| 메서드                          | 조건                                | 역할                                       |
| ------------------------------- | ----------------------------------- | ------------------------------------------ |
| `then(onFulfilled, onRejected)` | 앞 프로미스가 성공 또는 실패 완료   | 등록된 해당 콜백에 값 또는 이유 전달       |
| `catch(onRejected)`             | 앞 프로미스가 거부 됨               | `then(undefined, onRejected)` 와 같은 역할 |
| `finally(onFinally)`            | 앞 프로미스가 성공 또는 실패로 완료 | 인수 없이 실행되는 공통 정리 작업          |

새 메서드 모두 **새 프로미스**를 반환. 아래 규칙은 `then`과 `catch` 콜백 적용

| 콜백                       | 결과                      |
| -------------------------- | ------------------------- |
| 일반 값을 반환             | 그 값으로 이행            |
| 아무것도 반환하지 않음     | `undefined`로 이행        |
| 프로미스나 thenable을 반환 | 반환한 대상의 결과를 따름 |
| 예외를 던짐                | 그 예외로 거부            |

`finally`는 정상적으로 끝나면 앞선 값이나 거부 이유를 그대로 전달. 콜백에서 예외를 던지거나 거부된 프로미스를 반환하면 새 체인은 그 이유로 거부된다. 반환한 정리 작업이 프로미스면 완료를 기다림

```js
Promise.resolve(1)
  .then((value) => value + 1)
  .finally(() => console.log("정리 완료"))
  .then((value) => console.log(value)); // 2
```
